# 真实延寿，从哪里开始？

这里的“生命延续”指**真实人体的健康寿命研究**，不是数字人，也不是“AI 已经找到了长生药”。AI 可以帮助研究人员整理资料、分析数据、设计候选和提高实验效率；一个模型、一个生物年龄数字或一项动物实验，都不能单独证明人能活得更久。

这个入口先做三件事：展示可追溯的开源项目、说清它们能做和不能证明什么、给刚入门的人一件能完成的小任务。你不需要先会写代码。

想先看持续更新的论文、试验和项目线索，可打开已有的[AI 生命延续学雷达](https://radar.aibioo.cn/)。雷达帮你发现候选；下面的条目和任务帮助你核对、理解并参与。雷达的相关度分数不是医学疗效评分。

> **当前状态**：这是首批经过仓库页面核对的示例，不是完整大全、热度排名、临床推荐或产品背书。项目功能可能变化；每次使用前请打开原仓库确认。页面核对日期：2026-09-24。

## 先选你感兴趣的一条路

| 方向 | 看什么 | 第一件可以做的事 |
|---|---|---|
| 衰老测量 | pyaging、Biolearn | 核对一个工具的用途、输入数据和限制 |
| AI 药物与分子研究 | DeepChem、TDC、Boltz | 把英文项目说明整理成有来源的中文条目 |
| 科研资料查找 | BioMCP、ClinicalTrials.gov 数据接口 | 核对原始链接、项目版本或试验登记信息 |

### 衰老测量：研究工具，不是个人寿命预测

- [pyaging 官方仓库](https://github.com/lucascamillomd/pyaging)：提供多个生物衰老时钟的 Python 工具与资料。适合研究数据分析；时钟输出不等于“这个人还能活多少年”，也不证明某项干预延长了人体寿命。[看官方安装说明](https://pyaging.readthedocs.io/)。
- [Biolearn 官方仓库](https://github.com/bio-learn/biolearn)：帮助研究人员加载公开数据、分析衰老生物标志物，并运行部分衰老时钟。仓库说明它仍是预发布版本，接口可能变化；它不是个人诊断服务。[看官方文档](https://bio-learn.github.io/)。

### AI 药物与分子研究：上游能力，不是延寿疗法

- [DeepChem 官方仓库](https://github.com/deepchem/deepchem)：面向药物发现、化学和生物学的机器学习工具。它是通用科研工具，不是一个已经验证的人体延寿药物。
- [Therapeutics Data Commons（TDC）官方仓库](https://github.com/mims-harvard/TDC)：提供治疗科学研究所需的数据、任务与基准，便于开发和比较模型。模型基准成绩不能直接当作临床疗效。
- [Boltz 官方仓库](https://github.com/jwohlwend/boltz)：生物分子相互作用建模工具。结构或相互作用预测需要后续实验验证，不能直接推出药物安全或人体延寿效果。

### 找原始资料：先确认来源，再谈结论

- [BioMCP 官方仓库](https://github.com/genomoncology/biomcp)：把生物医学检索能力提供给 AI 工具，适合找论文、试验等线索。它帮你找到资料，不会替你证明医学结论。
- [ClinicalTrials.gov 官方数据接口](https://clinicaltrials.gov/data-api/api)：查询临床试验登记与结果资料的来源之一。**试验已注册、正在招募或已经结束，都不等于疗法有效。**

## 不会编程，也能做的第一项贡献

建议从“核对一个项目”开始，约十到三十分钟：

1. 从上面选一个项目，打开它的官方仓库，不依赖转述文章。
2. 用自己的话写两句：它实际提供什么；它**不能证明**什么。附上支持这两句的原始页面链接。
3. 记下你核对的日期。如果发现上面有失效链接、说过头的描述或版本变化，也直接指出。
4. [按中文模板提交项目资料或纠错](https://github.com/dongyu19920904/BioAI-Daily-Web/issues/new?template=project-entry.md)。需要 GitHub 账号；提交后还需维护者核查，提交不自动等于“已被接受的贡献”。

想做更深入的任务？可以把项目的入门步骤译成中文并标注原文位置，或尝试用公开示例数据复现一段教程。请勿上传个人体检、病历、基因数据或未经许可的论文全文。详细规则见[中文贡献说明](https://github.com/dongyu19920904/BioAI-Daily-Web/blob/main/CONTRIBUTING.md)。

## 这页如何继续长大

后续会把现有雷达发现的候选、核验过的项目、公开任务和纠错记录逐步接进来。后台可以用 AI 和 Windmill 帮忙去重和起草，但**候选不会因为热门或 AI 写得流畅就自动成为可信条目**。真正要看的不是页面有多少链接，而是有多少人能找到原始资料、完成任务，并得到可核查的反馈。

这页只介绍科研资料和开源参与，不提供个人医疗建议、检测报告解读、药物或补剂推荐。
