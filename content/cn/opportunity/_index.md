## 今日主推
### 表观时钟开源工具包 → 做成 Python 技能教程 + 开发者资料包
一个新的 GitHub 项目将 24 种表观遗传时钟（GrimAge、Horvath、PhenoAge 等）打包成可离线安装的 Python 技能包，只依赖 pandas 和 numpy。这为健康数据分析者、抗衰爱好者和轻量级开发者提供了低门槛试跑表观时钟的机会。

- **证据来源**：GitHub 项目 gangchen/epiage-skill，https://github.com/gangchen/epiage-skill ，发布于 2026-09-13，2 stars，Python 语言
- **可信度**：中 — 项目存在且开源，但 stars 少，需试跑验证可用性和文档完整度
- **目标鱼塘**：抗衰数据爱好者、健康科技自媒体、做 AI 健康工具的独立开发者、想学表观时钟但没有 R 或生信背景的人
- **痛点和付费理由**：现有表观时钟工具多需 R 或复杂环境，门槛高；这类人想试跑、理解或做轻量级演示，但不想陷入环境配置
- **可交付物**：试跑教程（安装到输出结果全流程）、表观时钟对比清单、开发者资料包、FAQ 文档、Notion/飞书知识库条目
- **适合做什么**：内容选题（"用 Python 试跑 24 种表观时钟"）、技术教程（面向非生信背景）、工具导航页条目、小红书/公众号科普、开发者社群引流
