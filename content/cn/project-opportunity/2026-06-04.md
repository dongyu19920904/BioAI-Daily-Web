# AI生命延续学资讯商机项目

## 今日优先项目

### Gladyshev-Lab/tAge
Gladyshev Lab 出品的转录组生物学年龄预测 R 包，从基因表达数据预测生理年龄，13 stars 但实验室背书强。
- 证据来源：[GitHub - Gladyshev-Lab/tAge](https://github.com/Gladyshev-Lab/tAge)
- 可信度：高（Gladyshev Lab 在衰老领域权威）
- 它解决什么问题：从 RNA-seq 或微阵列数据快速估算生物学年龄，可用于干预效果评估、队列分层
- 可做成什么：中文上手教程 + 公开数据集试跑 + 与其他衰老时钟（DNA 甲基化、蛋白质组）对比内容
- 售后或合规风险：低（纯研究工具，不直接面向临床诊断）
- 今天最小动作：clone 仓库，跑示例数据，记录依赖和输出格式，写 200 字试跑笔记

### biomarkersParkinson/paradigma
帕金森数字生物标志工具箱，16 stars，2026-06-02 更新，Python 实现。
- 证据来源：[GitHub - biomarkersParkinson/paradigma](https://github.com/biomarkersParkinson/paradigma)
- 可信度：中（项目名称专业，但缺作者机构信息）
- 它解决什么问题：从可穿戴设备、传感器数据提取帕金森病数字标志物（步态、震颤、运动模式）
- 可做成什么：数字生物标志物科普长文 + 可穿戴数据预处理教程 + 与 Apple Watch / Fitbit 数据对接方案
- 售后或合规风险：中（涉及医疗器械数据，需明确"仅供研究"边界）
- 今天最小动作：阅读 README 和示例代码，列出支持的传感器类型和输出指标，发一条"数字标志物工具箱"选题

### scAgeClock (gangcai/scageclock)
单细胞转录组人类衰老时钟，用 gated multi-head attention 神经网络，6 stars 但方向前沿。
- 证据来源：[GitHub - gangcai/scageclock](https://github.com/gangcai/scageclock)
- 可信度：中（单细胞 + 注意力机制是当前热点，但需验证训练数据和泛化性）
- 它解决什么问题：从单细胞 RNA-seq 数据预测细胞年龄，可用于组织特异性衰老研究
- 可做成什么：单细胞衰老时钟技术拆解 + 与 bulk RNA-seq 方法对比 + 数据集需求清单
- 售后或合规风险：低（研究工具）
- 今天最小动作：检查模型架构和预训练权重可得性，记录输入数据格式要求

## 可二次开发方向

- **衰老时钟对比仪表盘**：整合 tAge、scAgeClock、Horvath 时钟等工具，做成可视化对比页面，输入同一数据集，输出多种时钟预测结果和一致性分析
- **帕金森数字标志物监测 SaaS**：基于 paradigma 工具箱，做轻量级 API 服务，接收可穿戴设备数据，返回标准化帕金森风险指标，面向科研机构和临床试验团队
- **转录组年龄预测教程系列**：从数据获取（GEO/SRA）→ 预处理 → tAge 预测 → 结果解读，做成可复现 Jupyter Notebook，配中文注释
- **Alzheimer's 与 Huntington's 共享标志物数据库**：基于 PubMed 论文"MMP9 as a shared immune-related gene"，建立跨疾病共享生物标志物知识库，可做成检索工具或 Notion 数据库

## 值得观察

- **TimeFlies (rsinghlab/TimeFlies)**：果蝇头部单核 RNA-seq 衰老时钟，2 stars，配套 2026 年 Scientific Reports 论文。模式生物工具，短期商业化难，但可用于衰老机制科普内容或实验室方法对比
- **Tolion Brain Coach**：Tolion Health AI 发布的阿尔茨海默病预防 App（2026-05-12 新闻）。需观察实际功能、数据来源、临床验证和用户反馈，暂无开源项目或技术细节
- **SPISE 指数 + 集成学习心血管风险分层**（PubMed 论文）：CKM 综合征（心血管-肾脏-代谢）风险预测，方法可迁移到其他慢病，但需获取原始代码和数据集
- **自然环境与长寿关系**（Mastodon 社交信号）：科普向内容，可做成"绿色空间与健康"图文或视频，但缺乏可操作的数据集或工具

## 今天别碰

- **尿液代谢组学预测儿童脓毒症 AKI**（PubMed 论文）：临床研究，方法可解释但数据不公开，儿科医疗合规要求极高，不适合轻咨询或工具化
- **"一个关键因素比饮食运动更能预测长寿"**（Mastodon 社交信号）：标题党式科普，无具体研究链接或数据，无法验证，不建议作为内容素材
