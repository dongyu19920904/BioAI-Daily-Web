## 今日优先项目

### 1. CosinorAge — 昼夜节律生物钟龄预测 Python 包

ETH Zurich 出品，用可穿戴加速度计数据拟合昼夜节律参数，预测生物年龄。这是少有的"可穿戴数据→生物年龄"完整管道，和 Apple Watch / Garmin 数据方向直接对接，适合做试跑教程和科普拆解。

- **证据来源：** https://github.com/ADAMMA-CDHI-ETH-Zurich/CosinorAge
- **可信度：** 中（ETH Zurich 机构背书，stars 低但方向精准，需确认论文）
- **目标鱼塘：** 可穿戴用户、健康管理从业者、长寿内容读者、独立开发者
- **它解决什么问题：** 把手环/手表的睡眠+活动数据转换成可解释的"生物年龄"指标，比单纯 HRV 更有叙事性
- **试跑门槛：** 低，Python pip 安装，README 应有示例数据
- **可做成什么：** 试跑教程 / 内容拆解 / 小工具 demo / 资料库条目
- **可交付物：** README 试跑笔记、截图、3 条要点、一张"输入数据→输出生物年龄"流程图
- **最低成本验证：** `pip install` + 跑示例数据 + 截图，30 分钟内可完成
- **二次开发路径：** ① 接 Garmin/Apple Health 导出 CSV 做端到端 demo；② 做"你的昼夜节律年龄"小工具；③ 写成可穿戴生物年龄系列教程第一篇
- **售后或合规风险：** 低
- **合规边界：** 只写"研究工具、实验性预测，不构成医疗诊断"；不宣称能改善健康或指导治疗
- **今天最小动作：** 克隆仓库 → `pip install` → 跑示例 → 截图 + 记录 3 条要点 → 写一条小红书选题草稿："手环数据能算出你的生物年龄？ETH Zurich 这个工具我试了"

### 2. biomarkersParkinson/paradigma — 帕金森数字生物标志物工具箱

用可穿戴传感器数据提取帕金森病的数字生物标志物（步态、震颤、心率等），是"可穿戴数据用于神经退行性病变监测"方向的少有完整工具包，方向和 ADRD/dementia 照护者社群高度契合。

- **证据来源：** https://github.com/biomarkersParkinson/paradigma
- **可信度：** 中（stars 17，近期活跃，方向精准）
- **目标鱼塘：** 照护者、帕金森患者家属、神经科研究者、健康硬件观察者
- **它解决什么问题：** 从普通可穿戴设备提取帕金森相关特征，降低专业门槛
- **试跑门槛：** 中，需 Python 环境和示例数据集，依赖可能涉及 numpy/scipy
- **可做成什么：** 内容拆解 / 资料库条目 / 试跑教程 / 工具导航
- **可交付物：** 依赖安装记录、README 梳理、3 条要点、一张"功能模块对比表"
- **最低成本验证：** 读完 README + 列出功能模块 + 做一张表格，今天 1 小时内可完成
- **二次开发路径：** ① 做"帕金森数字监测工具导航"资料库条目；② 对接照护者社群做科普拆解；③ 后续接真实设备数据做 demo
- **售后或合规风险：** 中
- **合规边界：** 严格写"研究工具，不用于临床诊断或病情评估"；不暗示可替代神经科就诊
- **今天最小动作：** 读 README → 整理功能模块 → 做一张"支持哪些传感器/特征/输出"对比表 → 存入资料库

### 3. nopara73/LongevityWorldCup — 长寿运动平台（生物年龄竞赛）

开源的"长寿运动"平台，用生物年龄计算器做运动员排行榜。概念足够有趣，适合做内容拆解和选题，且 C# 代码可直接观察生物年龄算法实现逻辑，作为"生物年龄计算方法对比"的一手素材。

- **证据来源：** https://github.com/nopara73/LongevityWorldCup
- **可信度：** 低-中（个人项目，stars 20，概念新颖但未经同行评审）
- **目标鱼塘：** 长寿内容读者、健身+量化自我社群、内容创作者
- **它解决什么问题：** 把"生物年龄"变成可竞赛的公开指标，增加趣味性和传播性
- **试跑门槛：** 中（需 .NET 环境）
- **可做成什么：** 内容拆解 / 选题素材 / 资料库条目
- **可交付物：** 选题草稿、概念拆解笔记、"生物年龄竞赛平台"简介卡片
- **最低成本验证：** 读 README + 截图 + 写一条朋友圈/小红书选题，15 分钟
- **二次开发路径：** ① 做"生物年龄计算方法大横评"系列第一篇，以此为素材之一；② 跟踪项目发展，若活跃可做深度报道
- **售后或合规风险：** 低
- **合规边界：** 作为"有趣实验性项目"介绍，不做医疗类宣称
- **今天最小动作：** 读 README → 写一条小红书/朋友圈选题："有人做了一个'生物年龄奥运会'，用真实检测数据排名，这个方向值得关注吗？"

### 4. Lifespan.io 报道：细胞类型特异性衰老预测疾病发生

新研究用不同细胞类型的衰老轨迹预测阿尔茨海默症、肺癌等疾病，延伸 Tony Wyss-Coray（Stanford）的器官时钟研究。这是"生物年龄细分化"叙事的重要背景材料，适合做资料库条目和内容选题。

- **证据来源：** https://lifespan.io/cell-type-specific-aging-predicts-disease-onset/
- **可信度：** 中（Lifespan.io 报道，引用同行评审论文，需核查原始论文）
- **目标鱼塘：** 长寿内容读者、健康管理从业者、科研学习者
- **它解决什么问题：** 用细胞层面的衰老差异解释为何疾病风险因人而异，比"年龄一个数字"叙事更有深度
- **试跑门槛：** 低（内容层面，阅读+整理即可）
- **可做成什么：** 内容拆解 / 资料库条目 / 选题素材
- **可交付物：** 3 条要点摘要、一条科普选题草稿、资料库条目
- **最低成本验证：** 阅读全文 + 找到原始论文 + 写 3 条要点，20 分钟
- **二次开发路径：** ① 做"器官时钟/细胞时钟"系列科普的第一篇背景文；② 和 CosinorAge 联动，讲"从组织到细胞，生物年龄越来越精细"
- **售后或合规风险：** 低
- **合规边界：** 只写"研究发现、科学观察"，不写"你可以通过某检测预测自己的疾病"
- **今天最小动作：** 阅读 → 找原始论文 → 写 3 条要点 → 存资料库 → 起一条选题："年龄不止一个数字，你的细胞可能比你老得多"

## 值得观察

1. **neurogenetics/ADRD_Brain_Aging**（https://github.com/neurogenetics/ADRD_Brain_Aging）
   - 方向精准（ADRD + 脑老化），但 stars 仅 4，Jupyter Notebook 为主，内容和维护状态不明。
   - 暂缓原因：需先确认仓库活跃度、数据集是否公开可用、代码是否可跑通，门槛未经验证前不推。
   - 跟踪动作：收藏 + 每月检查一次更新状态。

2. **CRISPR 临床化进展（GEN 报道）**
   - 方向重要（基因编辑→长寿干预），但当前处于临床前/早期临床阶段，距离可操作内容距离远。
   - 暂缓原因：合规风险高，内容方向需专业背景才能准确表达，不适合轻量操作。
   - 跟踪动作：收藏报道链接，作为"基因编辑与长寿"系列的背景素材储备。

3. **LongevityWorldCup 平台发展**
   - 概念有传播性，但个人项目稳定性存疑，C# 技术栈较小众。
   - 暂缓原因：当前适合内容素材而非技术复用，待项目活跃度提升再考虑深度介入。
   - 跟踪动作：加星 + 3 个月后复查。
