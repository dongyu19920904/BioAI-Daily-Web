## 今日优先项目

### 1. 语音认知筛查可解释框架（Speech-Based Cognitive Impairment Detection）

这篇论文把黑盒 transformer 翻译成可读的临床叙述，结合 SHAP + LLM 四阶段推理，F1 达 72%。对"AI+认知衰退筛查"这条内容线来说，是目前技术侧可讲解性最强的一个切入点。

- **证据来源：** [arxiv/2606.27973 - From Black-Box to Clinical Insight](https://papers.cool/arxiv/2606.27973)
- **可信度：** 中（arxiv 预印本，未经同行评审发表，但方法描述完整、基准数据集公开）
- **目标鱼塘：** 长寿/认知健康内容读者、照护者、健康管理从业者、AI 工具开发者
- **它解决什么问题：** 语音能非侵入式筛查认知衰退，但 AI 模型不可解释、临床不信任；该框架让模型输出变成可读叙述，降低黑盒门槛
- **试跑门槛：** 中（需要读懂 SHAP 逻辑和 LLaMA 调用，但无需自己训练模型，能复现流程即可）
- **可做成什么：** 内容拆解 / 试跑教程 / 资料库条目
- **可交付物：** 论文 3 条要点笔记 + 一张"语音认知筛查技术路线对比表"（SHAP / 传统特征工程 / 端到端）
- **最低成本验证：** 今天读 abstract + 方法图，整理 3 条要点，写一条"AI 如何用你的声音判断认知衰退"小红书选题
- **二次开发路径：** → 整理语音认知筛查数据集清单 → 做工具导航页（开源模型 + 数据集 + 论文汇总）→ 面向照护者做"早筛方案对比"轻咨询资料包
- **售后或合规风险：** 高
- **合规边界：** 只能写"研究观察：论文显示语音特征与认知状态相关"，严禁表述为"可以诊断/检测认知障碍"，所有内容须标注"仅供参考，非医疗建议"
- **今天最小动作：** 读论文 abstract，整理 3 条要点，拟一条小红书/朋友圈选题："AI 听你说话就能判断认知退化？这篇论文讲清楚了原理"

### 2. 白天光照与降低痴呆风险（Brighter Daytime Light & Dementia Risk）

结论直接、读者好理解，光照 → 昼夜节律 → 认知保护这条逻辑链对可穿戴/环境传感器内容有很强的接驳价值。今天就能写成一条朋友圈或选题，零门槛。

- **证据来源：** [News-Medical Aging - Brighter daytime light is linked to a lower dementia risk](https://www.news-medical.net/news/20260629/Brighter-daytime-light-is-linked-to-a-lower-dementia-risk.aspx)
- **可信度：** 中（新闻报道，原始研究未附链接，需进一步核查期刊来源）
- **目标鱼塘：** 长寿内容读者、中老年健康管理关注者、可穿戴用户（有光照传感器的设备用户）
- **它解决什么问题：** 痴呆预防缺乏低门槛、可操作的日常干预线索；光照是成本极低、无需购买任何设备的生活方式变量
- **试跑门槛：** 低（只需读新闻 + 找原始研究摘要）
- **可做成什么：** 内容拆解 / 资料库条目 / 选题素材
- **可交付物：** 一条朋友圈/小红书选题 + 一条资料库条目（光照 × 昼夜节律 × 认知健康）
- **最低成本验证：** 今天写一条选题或朋友圈草稿
- **二次开发路径：** → 整理"昼夜节律 × 抗衰"研究资料库 → 接驳可穿戴光照数据（Oura / Apple Watch 环境光）做"自测清单" → 面向照护者做"家庭光照干预建议"资料包
- **售后或合规风险：** 低
- **合规边界：** 写"研究观察：光照与认知保护相关"，不写"光照可以预防/治疗痴呆"
- **今天最小动作：** 写一条选题草稿："每天多晒太阳，痴呆风险更低？最新研究说了什么"，收藏原文链接进资料库

### 3. 全脑衰老解剖-功能模型（SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age）

星数极少但方向准：161 名健康受试者（10–80 岁），用 BOLD + DTI 建衰老生物标志物模型。适合作为"脑衰老 biomarker"内容线的资料库条目，也适合做 README 试跑笔记。

- **证据来源：** [GitHub - SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age](https://github.com/SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age)
- **可信度：** 低（1 star，个人仓库，无配套论文链接，代码质量未知）
- **目标鱼塘：** 科研学习者、AI+神经科学方向独立开发者、长寿内容创作者
- **它解决什么问题：** 脑衰老 biomarker 缺乏可直接跑的开源小型项目；这个仓库提供了一个可观察的最小实现
- **试跑门槛：** 中（需要读 README，判断依赖可否安装；HTML 语言可能是 Jupyter notebook，门槛相对低）
- **可做成什么：** 试跑教程 / 资料库条目
- **可交付物：** README 试跑笔记（能跑就截图，不能跑就写"踩坑记录"）+ 资料库条目
- **最低成本验证：** 今天 clone 仓库，读 README，看依赖列表，判断能否 5 分钟内安装运行
- **二次开发路径：** → 作为"脑衰老开源工具"导航条目 → 如果数据可得，做数据清洗脚本示范 → 拆解成"机器学习判断大脑年龄"教程
- **售后或合规风险：** 中
- **合规边界：** 只写"研究性项目，仅供学习参考，非临床工具"
- **今天最小动作：** 打开 GitHub 仓库，读 README，看 notebook 结构，判断依赖，记录 3 条观察点
