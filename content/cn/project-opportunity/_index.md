## 今日优先项目

### NeuroBloom — 多发性硬化症纵向认知监测平台

这个项目用 Svelte 构建，免费开放，聚焦 MS 患者的认知康复跟踪，覆盖 35 个自适应认知任务、6 个认知域、双语（孟加拉语/英语）、数字生物标志物提取。对"AI 生命延续学"方向来说，它的核心价值不在于 star 数，而在于它把"认知衰退监测"这件事做成了可跑的 web demo，且有临床协作流程设计。

- **证据来源：** [GitHub - Adit-Mugdha-das/NeuroBloom](https://github.com/Adit-Mugdha-das/NeuroBloom)，2026-07-06 发布，1 star，Svelte
- **可信度：** 中（新项目，代码可见，但尚无外部同行评审或临床验证）
- **目标鱼塘：** 神经退行性疾病内容读者、照护者、健康管理从业者、独立开发者（想做认知健康工具的）、longevity 内容创作者
- **它解决什么问题：** 让 MS 患者及照护者可以在 web 端做标准化认知任务，医生端可查看纵向数据，降低认知衰退监测的门槛
- **试跑门槛：** 低—中（Svelte 项目，`npm install` + `npm run dev` 可本地跑；主要门槛是理解任务设计逻辑）
- **可做成什么：** 试跑教程、工具导航条目、认知测评工具横向对比表、内容拆解（"开源认知监测平台长什么样"）
- **可交付物：** README 试跑截图笔记 / 6 个认知域 + 35 任务的整理表格 / 工具导航条目 / 小红书/公众号选题草稿
- **最低成本验证：** 今天克隆 repo，跑起来截图，整理 3 条要点，做一张"认知域→测试任务"对应表
- **二次开发路径：** 1）汉化界面做中文认知测评 mini 工具；2）提取数字生物标志物模块，写成数据分析教程；3）结合 dementia 资料库做工具导航页条目
- **售后或合规风险：** 中（涉及认知评估，切勿以诊断工具宣传）
- **合规边界：** 只写"用于辅助记录和观察认知表现趋势"，不得写"诊断 MS"或"治疗认知衰退"；内容中注明"本工具供研究和自我记录参考，不替代专业医疗诊断"
- **今天最小动作：** `git clone` → `npm install` → `npm run dev` → 截图 → 写一条小红书选题："有人做了个免费认知测评平台，35个任务测6个维度，还能医生协作"

### SaraYCano — 全脑年龄相关解剖-功能模型

用 BOLD 信号 + DTI 结构连接性建立全脑衰老模型，161 名健康被试（10–80 岁），用机器学习识别衰老生物标志物。这是一个方向非常准确的学术项目，数据和方法层面可读性较高，适合做"脑衰老生物标志物"方向的文献地图或资料库条目。

- **证据来源：** [GitHub - SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age](https://github.com/SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age)，发布 2026-06-14，1 star，HTML
- **可信度：** 中（代码公开，有数据描述，但尚无同行评审论文链接可核实）
- **目标鱼塘：** longevity 内容读者、神经科学学习者、想做脑衰老科普的创作者、biomarker 研究跟踪者
- **它解决什么问题：** 提供一个可复现的"脑衰老定量模型"方法框架，用于识别与年龄相关的神经连接变化
- **试跑门槛：** 中—高（需要理解 BOLD/DTI 数据格式；但 HTML 展示层门槛低，可先读 README 和展示页）
- **可做成什么：** 文献地图条目、脑衰老生物标志物科普图文、研究方法拆解（BOLD+DTI+ML 三件套）
- **可交付物：** 资料库条目 / 方法论拆解笔记（BOLD 信号 → DTI → 熵产生 Φ → 年龄生物标志物）/ 一张"脑衰老研究方法路线图"表格
- **最低成本验证：** 今天读 README 和 HTML 展示页，整理"什么是熵产生 Φ + 为什么它能作为衰老标志物"3 条要点
- **二次开发路径：** 1）整合进"脑衰老 biomarker 研究地图"资料库；2）以此为案例做"AI 如何分析大脑衰老"科普教程
- **售后或合规风险：** 低（纯研究观察型内容，不涉及干预或诊断）
- **合规边界：** 内容定位为"研究方法学习笔记"，不写"可用于诊断脑衰老"或"预测阿尔茨海默症"
- **今天最小动作：** 读 README → 整理 3 条要点 → 记录进 longevity biomarker 资料库

### Dunedin Pace of Aging Clock — 生活方式干预对衰老时钟的响应

Fight Aging! 今日文章指出 Dunedin 衰老时钟对生活方式干预有响应，但同时明确警告：衰老时钟不能直接用于评估新型干预手段的效果。这个信号本身是一条高质量"反向科普"内容线索——帮读者理解"衰老时钟局限性"，建立更理性的认知，是今天最容易写成一篇内容的素材。

- **证据来源：** [Fight Aging! - Dunedin Pace of Aging Clock Responds to Lifestyle Interventions](https://www.fightaging.org/archives/2026/07/dunedin-pace-of-aging-clock-responds-to-lifestyle-interventions/)，2026-07-06
- **可信度：** 高（Fight Aging! 是该领域长期高质量来源，文章本身是文献综述型解读）
- **目标鱼塘：** 关注生物年龄检测的读者、购买或考虑购买衰老时钟检测服务的用户、longevity 内容读者
- **它解决什么问题：** 帮助读者理解"生物年龄时钟有哪些局限性"，避免被过度营销误导
- **试跑门槛：** 低（读原文，提炼核心论点即可）
- **可做成什么：** 内容拆解、科普选题、"衰老时钟怎么选/怎么看"工具导航文章
- **可交付物：** 一篇公众号/小红书草稿 / "主流衰老时钟对比表"（Dunedin / GrimAge / DunedinPACE / TruAge）/ 资料库条目
- **最低成本验证：** 今天读完文章，提炼"衰老时钟的 3 个局限性"，写成一条小红书选题或公众号导语
- **二次开发路径：** 1）做"主流衰老时钟横向对比表"（原理/数据来源/局限性/价格/适合人群）；2）升级为"生物年龄检测导航页"
- **售后或合规风险：** 低（信息整理，非诊断服务）
- **合规边界：** 只写"帮助理解和筛选研究信息"，不写"可以用 Dunedin 时钟评估你的抗衰方案是否有效"
- **今天最小动作：** 读文章 → 整理 3 个局限性要点 → 写一条小红书选题草稿："你买的生物年龄检测，真的能测出干预效果吗？"

## 值得观察

**1. 老药新用筛选方法（Fight Aging! 今日文章）**
文章讨论对现有获批药物进行衰老效果筛选的新方法，提到 rapamycin 类效果对比。目前文章是评论型，没有具体新工具或数据集可试跑。
- 暂不动原因：文章未附具体工具/数据集链接，方向模糊，合规风险中等（涉及药物用途讨论）

**2. NeuroBloom 的双语认知测评设计**
孟加拉语/英语双语设计提示了"多语言认知测评本地化"的需求，中文方向有潜力。但当前项目刚发布，代码成熟度未知。
- 暂不动原因：项目太新，稳定性未验证；汉化开发量不小，需先确认核心功能是否稳定

**3. SaraYCano 项目的 DTI 数据可访问性**
如果原始 DTI/BOLD 数据是公开的（如来自 HCP 或 ABIDE），则可以复现分析流程做教程。目前未确认数据来源是否公开。
- 暂不动原因：需先核实数据许可协议和下载门槛

**4. 子宫衰老研究的纵向追踪**
"子宫衰老与生育结局"是一个新兴的 reproductive aging 细分方向，未来可能出现更多生物标志物研究。目前只有一篇新闻，证据单薄。
- 暂不动原因：证据链不完整，内容方向敏感，受众定位需要精细化
