# AI生命延续学资讯商机项目

## 先看结论（可引用项目判断）

- **Brain-Aging (visionbyangelic/Brain-Aging, 6 stars)** 提供基于 FreeSurfer MRI 特征的脑年龄预测规范模型，在 OpenBHB 健康人群训练并在 OASIS-3 验证。今天可试跑 Jupyter Notebook 查看特征工程和模型流程，适合做成"脑龄预测工具对比表"或"MRI 生物标志物资料库条目"。**不能用于临床诊断**，README 自述不等于医学验证，仅适合科研学习或内容拆解。

- **NeuroBloom (Adit-Mugdha-das/NeuroBloom, 1 star)** 是面向多发性硬化症患者的免费认知监测平台，包含 35 个自适应认知任务和患者-临床医生协作流程。今天可试跑 Svelte 前端，适合整理成"认知监测工具导航"或"数字生物标志物提取方法笔记"。**涉及临床康复指导，合规风险高**，只能写工具观察和研究方法，不能宣称康复效果。

- **Evipedia Grok Bot (Lifespan.io 新闻)** 是基于 Grok AI + Evipedia MCP 服务器的长寿干预"第二意见"助手。今天**不能试跑**（无公开仓库），但可收藏作为"AI + 循证医学知识库"参考案例，适合写成"长寿 AI 助手工具对比"或"MCP 服务器在健康领域应用观察"。**不能替代专业医疗建议**，只能作为信息整理工具展示。

## 今日优先项目

### Brain-Aging：脑年龄预测规范模型与特征工程笔记

这是基于 MRI 形态学特征预测脑年龄的完整流程项目，包含 FreeSurfer 特征清单、健康人群规范模型和 OASIS-3 验证结果，适合做成脑龄生物标志物资料库条目或 MRI 数据处理教程。

- **证据来源**：[visionbyangelic/Brain-Aging](https://github.com/visionbyangelic/Brain-Aging)，2026-09-07 更新，6 stars，Jupyter Notebook
- **可信度**：中（GitHub 项目，使用公开数据集 OpenBHB 和 OASIS-3，但未经同行评议）
- **目标鱼塘**：脑健康内容读者、神经影像学习者、生物标志物研究观察者、长寿数据分析爱好者
- **它解决什么问题**：提供可复现的脑年龄预测流程，帮助理解 MRI 特征如何转化为衰老生物标志物
- **试跑门槛**：中（需要 Python 环境、Jupyter、FreeSurfer 数据处理基础，但有完整 notebook）
- **可做成什么**：内容拆解、试跑教程、MRI 特征资料库、脑年龄预测工具对比表
- **可交付物**：
  - FreeSurfer 特征清单整理（哪些特征用于预测、如何过滤）
  - 脑年龄差（brain-age gap）计算方法笔记
  - OpenBHB 与 OASIS-3 数据集对比表
  - Jupyter Notebook 试跑截图 + 3 条核心要点
- **最低成本验证**：今天安装依赖 + 跑一个 notebook + 截图 + 写 3 条特征工程要点
- **二次开发路径**：
  1. 整理成"脑年龄预测工具方法对比表"（对比不同模型、数据集、特征选择）
  2. 提炼成"MRI 生物标志物资料库条目"（FreeSurfer 输出特征说明）
  3. 扩展成"神经影像衰老标志物学习地图"（连接其他脑龄研究项目）
- **售后或合规风险**：中
- **合规边界**：只能写"研究方法观察""特征工程笔记""数据集对比"，不能写"诊断工具""脑健康评估服务"或"预测阿尔茨海默病风险"
- **今天最小动作**：
  1. 克隆仓库，安装依赖（requirements.txt）
  2. 打开一个 notebook，看特征筛选和模型训练流程
  3. 截图 + 写 3 条要点：用了哪些 FreeSurfer 特征、如何训练规范模型、brain-age gap 怎么算

### NeuroBloom：认知监测平台的产品拆解与数字生物标志物观察

这是面向多发性硬化症（MS）患者的免费认知监测 Web 平台，包含 35 个自适应认知任务、6 个认知领域、数字生物标志物提取和患者-临床医生协作流程，适合做成"认知监测工具导航"或"数字认知评估方法对比表"。

- **证据来源**：[Adit-Mugdha-das/NeuroBloom](https://github.com/Adit-Mugdha-das/NeuroBloom)，2026-08-10 更新，1 star，Svelte
- **可信度**：中（开源项目，功能描述详细，但无临床验证数据或发表论文）
- **目标鱼塘**：认知健康内容读者、MS 患者照护者、数字健康工具观察者、神经康复从业者
- **它解决什么问题**：提供免费、纵向、自适应的认知监测，支持患者自测 + 临床医生远程指导
- **试跑门槛**：低（Svelte Web 应用，可本地运行前端，查看任务设计和交互流程）
- **可做成什么**：产品拆解、认知任务设计对比、数字生物标志物提取方法笔记、工具导航
- **可交付物**：
  - "35 个认知任务 × 6 个认知领域"清单
  - 认知监测工具对比表（NeuroBloom vs 传统神经心理测验 vs 其他数字工具）
  - 数字生物标志物提取方法笔记（从任务操作到生物标志物的流程）
  - 产品截图 + 3 条设计亮点
- **最低成本验证**：今天安装前端依赖 + 本地运行 + 截图 + 列出 6 个认知领域和代表任务
- **二次开发路径**：
  1. 整理成"认知监测工具导航"（对比不同平台的任务设计、适用人群、数据导出）
  2. 提炼成"数字认知评估资料库条目"（任务类型、生物标志物定义、适用场景）
  3. 扩展成"认知康复工具选型指南"（为照护者或从业者提供工具对比和选择建议）
- **售后或合规风险**：高
- **合规边界**：
  - **绝对不能写**："MS 康复服务""认知功能诊断工具""临床治疗指导"
  - **只能写**："认知监测工具观察""任务设计方法笔记""数字生物标志物研究方向""工具功能对比"
  - **必须说明**：本项目无临床验证，仅供研究和学习参考，不能替代专业医疗评估
- **今天最小动作**：
  1. 克隆仓库，安装 Svelte 前端依赖
  2. 本地运行，截图任务界面
  3. 列出 6 个认知领域和 3-5 个代表任务，写 3 条设计亮点

## 可二次开发方向

- **脑年龄预测工具方法对比表**：整合 Brain-Aging 项目的 FreeSurfer 方法、其他基于深度学习的脑龄模型（如基于 T1-MRI 的 CNN 模型）、商业脑健康评估工具（如 BrainKey）的技术路线、数据集、验证结果和适用场景。**可交付物**：对比表（Google Sheets / Notion）。**最低成本验证**：先完成 Brain-Aging 项目试跑，再搜索 2-3 个其他脑龄模型的论文或项目，填入对比维度。**后续升级**：扩展成"神经影像衰老标志物学习地图"（连接项目、论文、数据集、工具）。

- **认知监测与数字生物标志物资料库**：基于 NeuroBloom 的任务设计，整理"认知领域 × 任务类型 × 数字生物标志物"的结构化资料库。**可交付物**：Notion / Airtable 数据库，每条记录包含认知领域、任务名称、生物标志物定义、适用人群、来源项目。**最低成本验证**：先完成 NeuroBloom 任务清单，再搜索 1-2 篇数字认知评估综述，补充其他任务和标志物。**后续升级**：连接更多开源认知监测项目（如 OpenCognition），做成"认知监测工具导航"。

- **MRI 特征工程与数据处理教程**：基于 Brain-Aging 项目的 Jupyter Notebook，提炼成"FreeSurfer 输出 → 特征筛选 → 规范模型训练"的可复现教程。**可交付物**：Markdown 教程 + Colab Notebook + 示例数据。**最低成本验证**：先跑通 Brain-Aging 项目，截图关键步骤，写 3-5 条核心要点和常见坑。**后续升级**：扩展成"神经影像生物标志物提取教程系列"（连接其他模态如 fMRI、DTI）。

- **长寿 AI 助手工具对比与 MCP 服务器应用观察**：基于 Evipedia Grok Bot 新闻，整理"AI 助手 × 循证医学知识库 × MCP 服务器"的应用案例对比。**可交付物**：对比表（Grok Bot vs ChatGPT plugins vs 其他健康 AI 助手）+ MCP 服务器在健康领域的应用观察笔记。**最低成本验证**：先收藏 Evipedia Grok Bot 新闻，搜索 2-3 个其他健康 AI 助手（如 Ada Health、Buoy Health），填入对比维度（知识来源、交互方式、适用场景、合规边界）。**后续升级**：跟踪 MCP 服务器标准在健康和长寿领域的应用案例，做成"健康 AI 工具雷达"。

- **Evipedia Grok Bot (Lifespan.io 新闻)**：基于 Grok AI 和 Evipedia MCP 服务器的长寿干预"第二意见"助手。**暂时不动原因**：无公开仓库或 API，无法试跑或验证功能，只能作为"AI + 循证医学"应用案例观察。**继续跟踪**：关注 Evipedia 是否开放 MCP 服务器接口或 Grok Bot 的技术细节，评估是否可做成 MCP 服务器应用教程或健康 AI 工具对比。

- **The Last Generation to Die 纪录片 (Tim Maupin, Lifespan.io)**：近未来电影，探讨首批真正的返老还童技术到来时的社会分配问题，已进入 Future Vision XPrize 前 65 名。**暂时不动原因**：这是文化内容项目，不是技术项目或数据集，无法做成工具或试跑教程。**继续跟踪**：作为"长寿叙事和公众认知"话题素材，可用于自媒体选题（"如果返老还童技术只有富人能用，会发生什么"），但不适合今天的项目筛选。
