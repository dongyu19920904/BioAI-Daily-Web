## 今日优先项目

### 1. NeuroBloom — 多发性硬化症纵向认知监测平台

这是一个免费开源的认知康复 Web 平台，覆盖 6 大认知域、35 项自适应任务，并带有数字生物标志物提取功能。对于"AI 生命延续学"方向，它是少见的既有临床框架、又有开源代码、又能直接试跑的认知追踪工具，适合做教程和工具导航。

- **证据来源：** [Adit-Mugdha-das/NeuroBloom](https://github.com/Adit-Mugdha-das/NeuroBloom)（GitHub，2026-07-06）
- **可信度：** 中（1 star，新项目，功能描述详细但尚未经社区验证）
- **目标鱼塘：** 认知健康内容读者、照护者、健康管理从业者、神经康复方向的独立开发者
- **它解决什么问题：** 普通人和照护者缺乏可操作的认知纵向监测工具；临床级工具通常封闭收费；本项目提供免费、多语言、开源的替代方案
- **试跑门槛：** 中（Svelte 项目，需 Node.js 环境，但 README 试跑应可完成）
- **可做成什么：** 试跑教程 / 工具导航条目 / 认知评估工具对比表 / 自媒体内容拆解
- **可交付物：** README 试跑截图笔记 / 6 大认知域任务清单 / 认知监测工具横向对比表
- **最低成本验证：** 今天 clone 仓库，跑通本地 dev 环境，截图 3 个认知任务界面，整理"它测什么、怎么用、适合谁"的 3 条要点
- **二次开发路径：** 整理成"免费认知自测工具导航"资料库条目 → 写成小红书/公众号"照护者如何给家人做认知追踪"教程 → 后续可做横向评测（对比 BrainCheck、Cambridge Brain Sciences 等商业工具）
- **售后或合规风险：** 中
- **合规边界：** 只写"信息整理与工具介绍"，不写"可以诊断认知障碍"或"替代医疗评估"；强调该工具为研究/参考用途，不构成临床诊断依据
- **今天最小动作：** `git clone` + 本地跑通 + 截图 + 整理一张"6 大认知域 × 任务数量 × 适用场景"对比表，顺手记一条小红书选题："开源免费！在家给家人测认知功能的工具来了"

### 2. 脑龄解剖-功能模型 — 年龄相关脑连接变化研究

161 名健康被试（10–80 岁）的全脑 DTI + BOLD 信号分析，用机器学习提取老龄化生物标志物。数据框架清晰，适合做"脑老龄化 biomarker 研究地图"的资料库条目，也适合科普内容选题。

- **证据来源：** [SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age](https://github.com/SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age)（GitHub，2026-06-14）
- **可信度：** 中（1 star，学术研究性质，HTML 主要为可视化/报告，代码量待确认）
- **目标鱼塘：** 长寿/抗衰内容读者、神经科学爱好者、生物标志物研究跟踪者
- **它解决什么问题：** 脑老龄化的定量描述缺乏直观可视化；该项目提供了跨年龄段的全脑熵产生和有向连接的系统分析框架
- **试跑门槛：** 高（DTI/BOLD 数据处理，依赖神经影像工具链，数据集需自备）
- **可做成什么：** 资料库条目 / 文献地图节点 / 科普内容选题 / 脑老龄化 biomarker 指标清单
- **可交付物：** "脑老龄化生物标志物研究地图"资料库条目 / 一张"方法 × 指标 × 年龄段"整理表
- **最低成本验证：** 今天只读 README 和 HTML 可视化报告，整理"它用了什么数据、测了什么指标、发现了什么"3 条要点，不需要跑代码
- **二次开发路径：** 归入"脑老龄化 biomarker 研究追踪"专题资料库 → 后续可对比其他脑老龄化 clock（BrainAge、DeepBrainNet）整理成导航 → 适合做"大脑如何随年龄变化"系列科普内容的数据来源
- **售后或合规风险：** 低（纯研究整理，无临床宣称）
- **合规边界：** 只写"研究观察与数据整理"，不写"可以预测你的脑龄或认知衰退风险"
- **今天最小动作：** 读 README + 浏览 HTML 可视化 + 记 3 条要点 + 收藏到"脑老龄化 biomarker"资料夹

### 3. 眼动与面孔识别老龄化衰退 — 新闻线索

年龄相关的面孔识别下降与眼动一致性降低有关。这是一个非常适合做自媒体拆解的认知老龄化研究发现，结合可穿戴眼动追踪设备（如 Tobii、Apple Vision Pro 等）有明显的内容关联。

- **证据来源：** [News-Medical Aging, 2026-07-14](https://www.news-medical.net/news/20260714/Face-recognition-declines-with-age-may-lie-in-how-your-eyes-move.aspx)
- **可信度：** 高（专业医疗新闻媒体，研究发现有明确方向）
- **目标鱼塘：** 长寿内容读者、可穿戴设备用户、认知健康关注者
- **它解决什么问题：** 老龄化认知下降机制的普通读者理解缺口；眼动这个角度新颖且直观
- **试跑门槛：** 低（内容整理为主，不需要跑代码）
- **可做成什么：** 自媒体内容拆解 / 小红书/公众号选题 / 认知老龄化系列内容节点
- **可交付物：** 一篇"为什么老了认不出脸？研究说是眼睛动得少了"科普草稿或选题卡片
- **最低成本验证：** 今天读完原文，写 3 条要点 + 1 条小红书选题标题 + 1 句核心结论
- **二次开发路径：** 归入"认知老龄化机制"内容系列 → 关联眼动追踪可穿戴设备观察 → 后续可做"5 种可以在家自测认知功能的方法"导航内容
- **售后或合规风险：** 低
- **合规边界：** 只写"研究发现与信息整理"，不写"眼动异常说明你认知衰退"
- **今天最小动作：** 读原文 + 写 1 条小红书选题 + 归入认知老龄化内容库

## 值得观察

**1. Higher-Order Cell Tracking Transformer（HOCT）**
细胞谱系重建的 CV 模型，技术上属于生物成像 AI 前沿。暂不动原因：目标鱼塘是生命科学研究者而非生命延续学内容读者，试跑需要显微镜图像数据集，内容转化路径不清晰。待有明确的老龄化/细胞衰老应用场景再跟进。

**2. Q²SAR 量子多核学习药物发现框架**
早期药物发现的量子机器学习方法，理论上与抗衰老药物筛选有关联。暂不动原因：量子计算依赖门槛高，无开源数据集验证，内容拆解需要较强的化学信息学背景，目前离实际可交付物太远。值得做一条"量子计算 × 长寿药物发现"选题备用。

**3. 黑色素瘤 MITF rheostat 定量模型**
肿瘤表型异质性的数学建模研究。暂不动原因：内容高度专业，目标读者是肿瘤生物学研究者，与生命延续学内容读者距离较大。若后续做"癌症与老龄化"专题时可作为数学建模案例引用。

**4. ADC 抗体偶联药物制造分析挑战（GEN ebook）**
制药前沿技术内容。暂不动原因：与生命延续学内容方向相关性低，且为商业软文性质资料，合规和可信度评估需要更多信息。

## 今天别碰

**1. 黑色素瘤 / MITF 模型用于内容拆解**
涉及肿瘤进展机制，数学模型复杂（PDE 多尺度模型），受众极小，内容转化成本极高，且触碰医疗边界风险大。今天不要把它包装成"AI 预测癌症"类内容，容易产生误导和合规问题。

**2. Q²SAR 量子 QSAR 框架用于"量子抗衰"内容**
量子计算 × 药物发现的概念容易被夸大成"量子技术治疗衰老"类伪科学内容。当前该框架尚未有可复现的开源代码和公开数据集验证，不应用于任何有效性宣称。

**3. 直接拿 NeuroBloom 做"认知诊断服务"推广**
NeuroBloom 是研究/康复辅助工具，不是诊断设备。如果把它包装成"帮你测是否有认知障碍"服务，立即进入医疗器械和诊断宣称的灰色地带，维权和监管风险高。
