## 今日优先项目

### 1. pyaging — GPU 优化衰老时钟合集

这是目前最完整的 Python 衰老时钟工具库之一，涵盖多种表观遗传时钟（Horvath、PhenoAge 等），129 stars、最近活跃、Jupyter Notebook 形态，试跑门槛相对可控。对「生命延续学」资料库来说是核心基础设施，适合今天直接跑 README。

- **证据来源：** [lucascamillomd/pyaging](https://github.com/lucascamillomd/pyaging)（GitHub，2026-08-01 更新）
- **可信度：** 中（开源项目，代码可验证，但具体算法实现细节需自行核查）
- **目标鱼塘：** 长寿内容读者、健康管理从业者、独立开发者、科研学习者
- **它解决什么问题：** 衰老时钟算法散落在各论文，缺乏统一可运行的实现；此库提供 GPU 加速的统一入口，降低复现门槛
- **试跑门槛：** 中（需要 Python 环境 + CUDA 可选，有 Notebook 示例，无 GPU 也可跑 CPU 模式）
- **可做成什么：** 试跑教程 / 内容拆解 / 工具导航条目 / 资料库核心条目
- **可交付物：** README 试跑笔记、「衰老时钟算法对比表」（输入数据类型 / 所需样本 / 输出指标 / 使用门槛）、资料库条目
- **最低成本验证：** 今天克隆仓库，跑通一个示例 Notebook，截图记录输出，整理 3 条要点
- **二次开发路径：** → 衰老时钟科普长文 → 「我跑了 5 种衰老时钟」教程系列 → 面向健康管理从业者的「如何选择衰老时钟」导览 → 轻量对比工具页
- **售后或合规风险：** 中
- **合规边界：** 只写「研究工具，输出为学术参考指标，不构成医疗诊断或健康建议」；避免写「测出你的真实年龄」「用它指导干预」
- **今天最小动作：** `git clone` → 跑 README 示例 → 截图 → 写 3 条要点 → 起草一条小红书选题「AI 能算出你的生物年龄吗？我跑了这个开源工具」

### 2. parkinson-wearable-digital-biomarkers — 帕金森步态冻结可穿戴检测

用可穿戴加速度计时序数据检测帕金森 FoG（步态冻结）的 Python 基线代码。虽然 stars 极少，但方向非常准：可穿戴数字生物标志物 + 神经退行性疾病，与「AI 生命延续学」核心方向高度吻合，适合做资料库收藏和内容拆解。

- **证据来源：** [mohamad679/parkinson-wearable-digital-biomarkers](https://github.com/mohamad679/parkinson-wearable-digital-biomarkers)（GitHub，2026-08-10 发布）
- **可信度：** 低-中（新仓库，stars 极少，需自行验证代码质量，但描述方向清晰）
- **目标鱼塘：** 可穿戴用户关注者、照护者社群、健康硬件观察栏目读者、神经退行性疾病内容创作者
- **它解决什么问题：** 帕金森患者步态冻结是跌倒高危因素，传统临床评估依赖医院；此项目提供用手腕/腰部加速度计做检测的研究基线
- **试跑门槛：** 中（Python + 可能需要示例数据集，需查 README 确认数据获取方式）
- **可做成什么：** 资料库条目 / 健康硬件观察内容 / 可穿戴数字生物标志物选题
- **可交付物：** README 收藏笔记、「可穿戴检测帕金森步态冻结：研究现状观察」内容草稿、资料库条目
- **最低成本验证：** 今天读完 README，记录：输入数据格式 / 依赖 / 有无示例数据 / 能否跑通，整理成一条资料库草稿
- **二次开发路径：** → 「可穿戴如何帮助帕金森患者」科普内容 → 数字生物标志物工具导航 → 照护者工具资料包
- **售后或合规风险：** 高
- **合规边界：** 严格定位为「研究观察和信息整理」，不写「用于诊断帕金森」「替代医疗评估」；所有表述加「仅限研究参考，不构成临床建议」
- **今天最小动作：** 读 README → 记录数据要求和运行门槛 → 写一条资料库草稿条目 → 收藏，暂不发布

## 值得观察

**1. Brain_Aging_CCS — NIMHANS EEG 脑龄指数流水线**
NIMHANS（印度国家精神卫生和神经科学研究所）的脑龄计算项目，EEG 数据 + 脑老化指数，方向准确。暂不动原因：stars 极少，项目发布仅 9 天，数据获取方式不明，需先确认是否有公开示例数据、运行环境是否可复现。下周再查 README 更新情况。

**2. 视网膜病理 AI 分诊论文（稀疏专家路由）**
视网膜检查作为衰老相关疾病早筛（糖尿病视网膜病变、AMD）有潜力，但此论文偏深度学习架构研究，试跑门槛高，无可直接调用的工具或数据集，不适合今天动。值得跟踪是否有对应开源实现发布。

**3. 阿尔茨海默症脑细胞图谱新研究**
免疫细胞与阿尔茨海默病进展的脑细胞图谱，内容价值高，但新闻摘要信息不足，需要找原始论文确认数据可信度和主要结论再做内容拆解。暂列为「下周核查原始论文后再写」。

**4. MS-EEGNet-TCN-HBSM — 儿科耐药性癫痫 EEG 预警**
方向有价值（EEG 数字生物标志物、实时风险预警），但暂不动原因：针对儿科癫痫患者，合规风险高；作为暑期研究项目，代码成熟度存疑；目标鱼塘与「生命延续学」核心读者群重合度低。
