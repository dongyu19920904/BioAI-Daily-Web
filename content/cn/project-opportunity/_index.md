## 今日优先项目

### SaraYCano — 全脑解剖功能模型与年龄关系

这是一个用 BOLD 信号 + DTI 结构连接性建立全脑衰老模型的 GitHub 项目，纳入 161 名 10–80 岁健康被试，输出有向连接度和熵产生（Φ）作为衰老生物标志物，并使用机器学习方法分类。虽然 star 数极低（1），但方向精准——脑衰老生物标志物 + ML 是当前 longevity 领域高热度叙事节点。HTML 语言说明是分析报告形式，适合直接读 README 拆解。

- **证据来源：** [SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age](https://github.com/SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age)，发布于 2026-06-14
- **可信度：** 中（小型学术项目，未经同行评审公示，数据集来源需核实）
- **它解决什么问题：** 用非侵入性神经影像数据量化大脑结构-功能随年龄的退行变化，尝试用 ML 找到可预测衰老程度的影像生物标志物
- **可做成什么：** 内容拆解（"AI 如何读懂大脑年龄"科普）/ 脑衰老生物标志物资料库词条 / 试跑 README + 方法论笔记 / 小红书/公众号选题"科学家怎么测你大脑几岁"
- **售后或合规风险：** 低（纯信息整理，不涉及诊断或干预建议）
- **今天最小动作：** 打开 GitHub 仓库，读完 README，整理 3 个核心概念（BOLD、DTI、熵产生Φ）写成一条微信/小红书选题草稿，备用发布

## 可二次开发方向

- **脑龄 biomarker 科普词条库**：以 SaraYCano 项目为起点，整理"脑年龄评估"相关技术词汇（BOLD fMRI、DTI、图论连接组、熵产生），做成面向非专业读者的术语解释卡片或 Notion 数据库，可持续更新。
- **免疫衰老系列内容矩阵**：以今日免疫新闻为第一篇，规划「衰老与免疫」系列：免疫老化悖论 → 慢性炎症（inflammaging）→ 自身免疫与年龄 → 干预手段研究现状，每期一篇，适合公众号/小红书。
- **医疗设备校准与可穿戴可信度对比表**：以电气工程校准新闻为触点，整理市面主流健康可穿戴设备（Oura、Apple Watch、连续血糖仪等）的校准标准与患者安全相关公开资料，做成一张横向对比表。
- **Buck Institute 研究人员追踪页**：Parminder Singh 的研究方向（内分泌+免疫+衰老）是值得持续观察的 Buck 科学家，可建立一个简单的研究员追踪文档，每月更新其最新论文和研究进展，作为资料库的人物节点。

## 值得观察

- **Buck Institute Faces of Discovery 系列**：Parminder Singh 的背景横跨内分泌与免疫衰老，Buck Institute 每月更新该系列，是追踪前沿衰老研究人员动态的稳定来源。暂时内容不够密集，但可作为资料库人物节点持续收录。
- **医疗设备电气工程与患者安全交叉领域**：News-Medical 的设备校准报道暗示了一个持续存在的需求——消费者和从业者如何判断健康设备的测量可信度。这个方向暂无具体项目可做，但值得关注可穿戴设备校准标准相关的监管动态（FDA、CE 认证进展）。
- **全脑连接组衰老研究的数据集生态**：SaraYCano 项目使用的 161 人数据集来源未明，值得追踪其是否来自公开数据集（如 HCP、UK Biobank 子集），若是，则有可能基于同数据集做复现教程或对比分析内容。
- **自身免疫 + 衰老交叉的临床研究管线**：今日综述揭示机制，但干预侧（如靶向免疫衰老的药物/检测）仍处早期，值得用 ClinicalTrials.gov 持续监测相关注册试验，作为未来内容的数据支撑。

## 今天别碰

- **直接基于 SaraYCano 项目做诊断类内容或工具**：该项目 star=1，无同行评审，数据集来源未验证，模型未经临床验证。直接包装成"测大脑年龄"工具或诊断辅助内容，医疗合规风险高，且误导读者的可能性大。
- **将免疫衰老新闻包装成抗衰干预推荐**：综述只说明机制，尚无经验证的干预路径对应，若直接延伸为"这些方法能延缓免疫衰老"的推荐内容，属于夸大解读，医疗风险中到高。
- **从电气校准新闻直接做设备评测或推荐**：原文信息量极少，仅为方向提示，无足够素材支撑严肃对比评测；此时做设备推荐内容容易流于广告或错误信息，维护成本也高。
