## 今日优先项目

### 1. Gladyshev-Lab/tAge — 转录组生物年龄预测 R 包

这是 Gladyshev 实验室（哈佛抗衰老领域知名团队）发布的工具，可从基因表达数据预测生物年龄，方向直接对应 longevity biomarker 核心需求。近期发布（2026-06-17），活跃度刚起步，适合提前关注。

- **证据来源：** [Gladyshev-Lab/tAge](https://github.com/Gladyshev-Lab/tAge)（GitHub，Stars: 19，Jupyter Notebook）
- **可信度：** 中高（实验室背景可查，但工具本身尚属早期，未经大规模验证）
- **它解决什么问题：** 让研究者用基因表达谱估算个体生物年龄，比时序年龄更能反映衰老状态
- **可做成什么：** 工具介绍内容拆解 / 试跑 README 教程 / "生物年龄预测工具盘点"资料库词条
- **售后或合规风险：** 低（纯研究工具，不涉及直接诊断）
- **今天最小动作：** 打开 README，整理 3 条要点（输入什么数据、输出什么、依赖环境），写成一条小红书/公众号选题草稿："哈佛抗衰老实验室刚发布一个生物年龄预测工具，我试了一下"

### 2. biomarkersParkinson/paradigma — 帕金森数字生物标志物工具箱

Python 工具包，专门做帕金森病可穿戴/数字生物标志物分析，方向覆盖 aging + neurodegenerative disease + 可穿戴数据，三个关键词全中。近期发布（2026-06-18），可以做成"神经退行性疾病数字监测工具"系列第一篇。

- **证据来源：** [biomarkersParkinson/paradigma](https://github.com/biomarkersParkinson/paradigma)（GitHub，Stars: 16，Python）
- **可信度：** 中（项目结构合理，但 star 数低，维护持续性待观察）
- **它解决什么问题：** 从可穿戴设备数据中提取帕金森相关数字生物标志物（如步态、震颤）
- **可做成什么：** 试跑教程 / 可穿戴数据分析工具导航词条 / "用手机/手表数据检测帕金森风险"科普内容选题
- **售后或合规风险：** 中（内容涉及疾病检测，需保守表达，只写"信息整理和研究观察"，不写诊断建议）
- **今天最小动作：** 克隆仓库，跑 README 示例数据，截图记录输入输出，做一张"它能分析什么指标"的简单对比表

- **证据来源：** [neurogenetics/ADRD_Brain_Aging](https://github.com/neurogenetics/ADRD_Brain_Aging)（GitHub，Stars: 4，Jupyter Notebook）

- **可做成什么：** 资料库词条 / 内容拆解（"哪些 GitHub 项目在研究大脑老化"）
- **售后或合规风险：** 低（纯研究资料整理）

## 可二次开发方向

- **"生物年龄预测工具横向对比表"**：把 tAge（转录组）、DNA 甲基化时钟（Horvath 等）、可穿戴步态评分等不同维度的生物年龄工具做成一张对比表，适合资料库或公众号长图。
- **"可穿戴数据 × 神经退行性疾病监测"教程系列**：以 paradigma 为起点，扩展至步态分析、手部震颤检测等场景，做成"硬件 + 算法"双线拆解教程，适合小红书或知识星球。
- **ADRD 脑老化研究工具导航页**：收录 GitHub 上 dementia / brain aging 相关活跃项目，做成定期更新的工具导航，吸引对认知健康感兴趣的读者。
- **"今天能跑的抗衰老研究工具"系列教程**：面向非科研背景读者，每期选一个可本地运行的 longevity 工具，做 README 试跑笔记，降低读者上手门槛。

## 值得观察

- **表观遗传药物 × 心血管脂肪靶向**（Lifespan.io 报道）：转录抑制剂靶向血管周围脂肪改善心血管代谢疾病，方向前沿，但目前仍是动物/早期研究阶段，尚无可操作工具或数据集，值得持续跟踪，等待人体试验数据。
- **Senolytic + 干细胞联合疗法**（Fight Aging! 报道）：小鼠模型结果，离人体应用距离远，但 senolytic 方向长期热度不减，适合作为"衰老细胞清除"内容选题的背景素材储备。
- **Chinmayee04-sys/Digital-biomarkers-using-machine-learning**：用面部情绪识别检测压力/焦虑/抑郁风险，方向有趣，但项目仅 1 star，代码质量和可靠性未知，等待更多活跃信号再决定是否深入。
- **机器人实验室协议翻译框架**（Dual-Agent，Papers.cool）：自动化生物实验流程的 AI 框架，长期可能与 longevity 研究加速相关，当前对自媒体内容创作无直接切入点，持续观察。
