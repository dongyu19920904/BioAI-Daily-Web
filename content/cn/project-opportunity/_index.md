## 今日优先项目

### 1. dstamou/vitalage — HealthKit 生物年龄估算工具

这是一个用 TypeScript 写的自托管工具，从 Apple Health 的 HRV、静息心率、睡眠、活动数据估算生物年龄，定位是 WHOOP Healthspan Score 的开源平替。虽然 stars 只有 1，但方向精准：可穿戴数据 + 生物年龄 + 自托管，正好覆盖长寿自我监测的核心需求。

- **证据来源：** GitHub 项目 dstamou/vitalage https://github.com/dstamou/vitalage
- **可信度：** 中（新项目，功能和算法细节需要试跑验证）
- **目标鱼塘：** Apple Watch 用户、长寿内容读者、健康自测爱好者、量化自我社群、健康管理博主
- **它解决什么问题：** WHOOP 的 Healthspan 需要订阅付费且不透明；这个工具让用户用自己的 HealthKit 数据在本地估算生物年龄，无需付费或上传数据
- **试跑门槛：** 中。需要 Node.js 环境、Apple Health 数据导出（iPhone 可导出 XML），TypeScript 项目需要基本 npm 操作
- **可做成什么：** 试跑教程 / 内容拆解 / 工具导航 / 对比表（vs WHOOP / Oura / Garmin Body Battery）
- **可交付物：** README 试跑笔记、截图流程、3 条要点总结、与 WHOOP Healthspan 的对比表、小红书选题「免费版 WHOOP 生物年龄怎么算」
- **最低成本验证：** 今天只需克隆仓库、读完 README、整理 3 个问题（数据格式、算法来源、输出是什么），不需要跑出结果
- **二次开发路径：** 1）制作「Apple Health 导出 → 生物年龄」图文教程；2）整理同类工具对比表（vitalage / Rejuve / biological age apps）；3）如果算法有文献依据，可做一篇「生物年龄计算逻辑拆解」内容
- **售后或合规风险：** 中
- **合规边界：** 只写「基于可穿戴数据的研究性估算工具」，不写「可以测出你的真实生物年龄」或「能预测疾病风险」；所有输出标注仅供参考，不构成医疗建议
- **今天最小动作：** `git clone` + 读 README + 记录：输入数据格式是什么、生物年龄用什么公式计算、有没有文献引用 → 整理成 3 条要点 → 存入资料库

### 2. zy-251026/MAR3D — 脑年龄估算 3D 神经网络

用 3D 神经网络从脑部影像估算脑年龄，stars 只有 3，但「脑年龄偏差（BAG）」是认知衰老研究的核心 biomarker 之一，方向直接服务 aging / dementia 领域。作为内容素材和资料库条目价值高，试跑需要 MRI 数据和 GPU，不适合零门槛上手。

- **证据来源：** GitHub 项目 zy-251026/MAR3D https://github.com/zy-251026/MAR3D
- **可信度：** 中（新项目，需要读代码确认数据集和模型来源）
- **目标鱼塘：** 神经科学/老年病研究学习者、AI + 脑健康内容读者、科研工具导航用户
- **它解决什么问题：** 脑年龄估算是认知衰老早期发现的重要研究工具，现有模型多为 2D 或浅层结构，3D 方法在精度上有优势
- **试跑门槛：** 高。需要 MRI 数据集（如 UK Biobank / ADNI）、GPU 环境、Python 深度学习依赖
- **可做成什么：** 内容拆解 / 资料库条目 / 工具导航（脑年龄估算工具全景）
- **可交付物：** 「脑年龄估算工具地图」资料库条目、README 笔记（模型结构 + 数据集 + 引用论文）、内容选题「AI 怎么从 MRI 推算你的大脑老了多少岁」
- **最低成本验证：** 今天只读 README 和代码结构，记录：用什么数据集训练、模型架构关键点、有没有对应论文，整理成资料库一条记录，不需要跑模型
- **二次开发路径：** 整理「脑年龄估算工具全景对比表」（MAR3D / BrainAge / DeepBrainNet 等）→ 做成工具导航页或公众号系列内容
- **售后或合规风险：** 低（纯内容整理，不涉及向用户提供诊断）
- **合规边界：** 只写「研究用脑年龄估算模型」，不写「能检测阿尔茨海默症」或「可以诊断认知衰退」
- **今天最小动作：** 读 README → 记录数据集来源和模型架构 → 在资料库中新建「脑年龄估算工具」条目 → 写一条内容选题备用

### 3. 时间限制饮食与失智症风险 — 新闻线索

一项小型临床试验结果显示，缩短每日进食窗口（时间限制饮食 / TRE）可能与降低老年女性失智症风险有关。这条新闻方向明确：生活方式干预 + 认知老化，是长寿内容读者最容易吸收的实用选题，且合规风险低（只需保守表述）。

- **证据来源：** News-Medical — Aging https://www.news-medical.net/news/20260726/Time-restricted-eating-may-help-lower-dementia-risk-in-older-women.aspx
- **可信度：** 中（小型临床试验，结论初步，尚未大规模复现）
- **目标鱼塘：** 中老年女性读者、照护者、健康生活方式内容消费者、失智症预防关注者
- **它解决什么问题：** 大众对「能不能用生活习惯降低失智风险」有强需求，但信息分散且夸大效果的内容很多；这条新闻提供了有据可查的初步依据
- **试跑门槛：** 低。只需要读原文 + 整理要点 + 找原始论文摘要
- **可做成什么：** 自媒体内容 / 朋友圈选题 / 小红书图文 / 资料库条目
- **可交付物：** 一条小红书/公众号选题、3 条要点卡片内容、「TRE 与认知健康」资料库条目
- **最低成本验证：** 今天读完新闻原文 + 找到原始试验摘要，整理「试验规模、干预方式、主要发现、局限性」4 个要素
- **二次开发路径：** 整理「生活方式干预与失智症风险」文献地图 → 做成定期更新的「防失智研究追踪」栏目
- **售后或合规风险：** 低（保守表述即可）
- **合规边界：** 只写「小型试验初步结果提示可能有关联」，不写「TRE 可以预防失智症」或「每天限时吃饭就能不得老年痴呆」；加上「仅供信息参考，不构成医疗建议」
- **今天最小动作：** 找到原始论文摘要（PubMed 搜索）→ 记录 4 个要素 → 写一条小红书选题草稿：「研究发现：每天只在这个时间窗口吃东西，可能帮助老年女性降低失智风险——但要注意这些局限」

- **后续升级路径：** 每周追踪 2-3 篇 → 做成 Newsletter 栏目或知识星球内容

**4. HealthKit 数据导出教程 + 数据字段说明资料库**
vitalage 需要 Apple Health 数据，但大多数用户不知道怎么导出或字段含义。这是一个独立的教程选题。
- **可交付物：** 「Apple Health 数据导出 → 字段说明 → 可接哪些工具」图文教程
- **最低成本验证：** 今天只在 iPhone 上操作一次导出，截图记录步骤
- **后续升级路径：** 扩展成「Apple Health 数据应用指南」系列 → 联动 vitalage / 其他分析工具

## 值得观察

**1. bag-of-waves — 可解释 EEG biomarker 框架**
论文方向是从 EEG 信号中提取可解释的波形模式，用于神经系统疾病诊断，与 aging/dementia 有潜在关联。
暂时不动原因：需要 EEG 数据集和信号处理背景，试跑门槛高；当前没有开源代码仓库链接，只有论文；内容拆解需要较强专业基础。
跟踪建议：等代码开源后再评估；可先收藏论文链接，关注是否有作者放出 demo。

**2. Axiom Biosciences（原 Cytonus Therapeutics）香港 IPO**
再生疗法公司准备在香港上市，涉及靶向生物制剂。对长寿投资观察、生物科技资讯栏目有参考价值。
暂时不动原因：IPO 新闻背景多，实质细节需要等招股书；再生疗法合规边界重，不适合直接推荐产品；与当前项目偏重工具和内容的方向关联弱。
跟踪建议：关注招股书披露时间，可做一条「长寿生物科技投资观察」资讯条目。

**3. Loom — 空间转录组学可视化系统**
分析组织切片中基因表达的空间分布，是分子老化研究的基础工具之一。
暂时不动原因：高度专业，试跑需要生物信息学背景和专有数据；目标鱼塘限于科研社群，内容拆解受众极窄；维护成本高。
跟踪建议：适合做「单细胞/空间组学老化研究工具」长期资料库条目，不适合近期做教程。
