报告日期：2026-08-16

## 今日优先项目

### epiage-skill — 24条表观遗传时钟打包成可离线运行的 Agent Skill

这是今天素材里唯一一个能立刻 clone、本地跑通并截图产出内容的项目。24条主流衰老时钟（GrimAge、PhenoAge、Horvath 等）全部打包、依赖极简（pandas+numpy），不需要 GPU 也不需要云账号，是做"表观遗传时钟入门科普"最好的实物素材之一。Stars 只有 2，但方向精准，最近发布。

- **证据来源：** [gangchen/epiage-skill](https://github.com/gangchen/epiage-skill)，GitHub，2026-08-09
- **可信度：** 中（项目新、stars少，功能描述清楚但需本地验证代码是否可跑）
- **目标鱼塘：** 长寿内容读者（想了解"生理年龄检测"的人）、健康管理从业者、独立开发者、想做抗衰 AI 工具的人
- **它解决什么问题：** 把散落在不同论文里的24条表观遗传衰老时钟集中成一个可调用的 Python skill，降低"研究生理年龄"的入手门槛
- **试跑门槛：** 低。只需 Python + pandas + numpy，clone 后按 README 跑即可
- **可做成什么：** 试跑教程 / 内容拆解 / 工具导航条目 / 资料库条目（"24条衰老时钟对比表"）
- **可交付物：** README 试跑截图 + 3条要点笔记 + 24条时钟对比表（名称/适用组织/年代/核心特点）
- **最低成本验证：** 今天只做：clone → 安装依赖 → 看能否 import → 截图 README → 整理出时钟名称清单
- **二次开发路径：** ① 做成"表观遗传时钟导航"资料库条目 → ② 写对比教程（各时钟区别是什么、测的是什么）→ ③ 如有用户数据，做一个最简 demo 输入样本甲基化值返回时钟分数 → ④ 长期可接入可穿戴/血液数据分析流程
- **售后或合规风险：** 中
- **合规边界：** 这是研究/学习工具，不可宣称"测出你的真实生理年龄"或"预测寿命"。所有内容只写"研究中使用的生理年龄估算方法"，明确注明"仅供学习研究，不构成医疗建议"
- **今天最小动作：** `git clone https://github.com/gangchen/epiage-skill` → 安装依赖 → 跑通 README → 截图 → 做一张"24条表观遗传时钟快速对比表"备用

**2. "TIMP2 / 青春蛋白"研究观察资料条目**
- 基于今日 Mount Sinai 新闻，TIMP2 逆转小鼠小胶质细胞衰老变化，是"血液年轻因子"叙事的新证据
- **可交付物：** 一条资料库条目（研究机构、结论、物种、阶段）+ 一条小红书/朋友圈选题草稿
- **最低成本验证：** 读原文摘要（15分钟）→ 写3条要点 → 注明"动物研究，距人体应用尚远"
- **后续升级路径：** → 加入"年轻血浆/蛋白因子"追踪列表 → 与 GDF11、klotho、FGF21 等同类研究做横向对比表
- **合规边界：** 只写"动物实验观察"，不写"可以延缓人类大脑衰老"

**3. Macaca_mulatta 脑衰老转录组流程——数据分析教程素材**
- 猕猴前额叶皮层 RNA-seq 衰老分析，包含完整 QC→STAR/HISAT2→DESeq2→GSEA 流程
- **可交付物：** 流程图（分析步骤可视化）+ "脑衰老转录组分析标准流程"资料库条目
- **最低成本验证：** 读 HTML 报告（无需跑代码）→ 截图流程 → 整理步骤清单
- **后续升级路径：** → 做成"longevity bioinformatics 入门教程"的案例章节 → 服务科研学习者鱼塘

**4. "生理年龄检测服务"资料包雏形**
- 以 epiage-skill 为核心，整合：① 当前市售甲基化检测服务（TruMe、Elysium 等）② 各时钟适用范围 ③ 价格区间 ④ 合规注意事项
- **可交付物：** 对比表 + 1篇"如何读懂你的表观遗传年龄报告"科普草稿
- **最低成本验证：** 今天只收藏 3 个市售服务页面 + 记录价格和宣传语
- **后续升级路径：** → 加入用户评价整理 → 做成"抗衰检测导航"工具页

## 值得观察

**1. TIMP2 / 小胶质细胞研究线索**
Mount Sinai 的研究角度清晰（youth-associated protein TIMP2 → 微胶质细胞功能），但目前仅限小鼠，距人体应用和商业化尚有距离。暂不做产品，但值得加入"血液年轻因子追踪清单"，等候 Phase 1 临床信号。
**暂不动原因：** 动物研究，人体阶段不明，宣传风险高。

**2. Macaca mulatta 脑衰老转录组（mateomics 项目）**
这是一个完整的生信分析案例仓库，但 stars=1，HTML 报告形式需要确认能否直接浏览。适合"bioinformatics for longevity"教程方向，但目标鱼塘是科研学习者，受众较窄。
**暂不动原因：** 目标鱼塘小、依赖 RNA-seq 背景知识、短期变现路径不清晰；等有 bioinformatics 教程需求时再用作案例素材。

**3. CDMO/AI制造扩张趋势（GEN 报道）**
Fujifilm 等 CDMO 正在扩展 AI 能力和制造设施，是"生物制药产业基础设施"的背景信号。与长寿/衰老主题关联较弱，但如果未来做"抗衰药物研发产业链"选题时有参考价值。
**暂不动原因：** 与今日核心方向（表观遗传、生理年龄、个人健康工具）关联较远；是产业背景，不是可试跑项目。

**4. 全球癫痫负担与医疗可及性数据**
与 aging 有一定交叉（神经退行性疾病、老龄化人群负担），但今天的报道角度是公共卫生不平等，商业切入点不清楚，目标鱼塘模糊。
**暂不动原因：** 与本项目核心方向（个人longevity工具、生理年龄）偏离；目标鱼塘和可交付物均不清晰。

## 今天别碰

**1. 直接用 epiage-skill 做商业"生理年龄测算服务"**
代码功能需本地验证，Stars=2 项目尚未经社区检验，且任何"帮用户测算生理年龄"的服务涉及医疗宣称风险。在未核实代码准确性、未取得合规咨询前，不能对外宣传检测结论。**风险：中-高，宣传失实 + 合规问题。**

**2. 基于 TIMP2 小鼠研究写任何"抗衰蛋白可逆转大脑衰老"的推广内容**
只有动物实验，无人体临床数据。此类宣传极易触发平台违规（尤其小红书、微信对医疗健康内容审核趋严），且误导读者。今天只能写"动物研究观察"，不能写效果宣称。

**3. 在无 RNA-seq 背景的情况下硬推 Macaca 转录组教程**
流程涉及 STAR/HISAT2/DESeq2，学习门槛高，非生信背景的自媒体读者消化不了。强推反而损耗信任度，维护成本高，短期无法变现。
