## 今日优先项目

### 1. White Matter Brain Age（白质脑龄估算）

这是一个用 ROI 特征和 3D-ResNet 两种方法估算脑龄的 Jupyter Notebook 代码库，直接对应「脑龄生物标志物」这条长寿学核心赛道。虽然 star 数只有 1，但刚发布、方向精准，适合作为内容拆解素材和脑龄话题的技术锚点。

- **证据来源：** [zayleakua/White-Matter-Brain-Age](https://github.com/zayleakua/White-Matter-Brain-Age)（GitHub，2026-07-08 发布）
- **可信度：** 中（新库，无论文佐证，但技术路线成熟，ROI + 3D-ResNet 是该领域主流方法）
- **目标鱼塘：** 长寿内容读者、科研学习者、对脑健康感兴趣的可穿戴用户、神经科学方向的独立开发者
- **它解决什么问题：** 用 MRI 数据估算白质/灰质脑龄，量化大脑衰老速度，是无创脑健康评估的研究工具
- **试跑门槛：** 中（需要 Python + Jupyter 环境；MRI 数据需自备或用公开数据集如 IXI/UK Biobank 子集；3D-ResNet 训练需 GPU，但 README 试跑只看结构不需跑完整训练）
- **可做成什么：** 内容拆解 / 试跑教程 / 资料库条目 / 脑龄检测方法对比表
- **可交付物：** README 试跑笔记、「脑龄 vs 实际年龄」科普对比表、小红书/公众号选题草稿
- **最低成本验证：** 今天只读 README + 整理 3 个核心问题（什么是脑龄差？白质 vs 灰质脑龄有何区别？普通人如何解读？）
- **二次开发路径：** 整理「脑龄生物标志物」资料库条目 → 做脑龄检测方法导航页 → 后续接入公开 MRI 数据集做可视化小 demo
- **售后或合规风险：** 中
- **合规边界：** 只写「研究用脑龄估算方法观察」，不写「可用于诊断认知疾病」或「能预测阿尔茨海默症」；所有表述限定为研究信息整理
- **今天最小动作：** 打开 README，截图记录主要模块结构，写一条选题：「你的大脑比你的身份证老几岁？脑龄估算技术现在能做到什么」

### 2. IBAR-ROGEN/Aging（甲基化衰老时钟 + 长寿变异注释）

这是一个完整的衰老生物信息学分析流程库，包含甲基化衰老时钟（Methylation Aging Clocks）、长寿相关变异注释和等位基因频率比较工具。三个模块都是当前长寿学研究的核心热点，适合做成资料库和方法论内容。

- **证据来源：** [IBAR-ROGEN/Aging](https://github.com/IBAR-ROGEN/Aging)（GitHub，2026-06-29 发布）
- **可信度：** 中（关联 ROGEN 项目，有明确研究背景；star 数低但内容完整度较高，需打开确认）
- **目标鱼塘：** 长寿内容读者、科研学习者、健康管理从业者、对表观遗传检测感兴趣的读者
- **它解决什么问题：** 整合多种衰老时钟算法 + 基因组长寿位点分析，是研究者复现或学习衰老表观遗传学的工具集
- **试跑门槛：** 中（Jupyter Notebook，需要 R 或 Python 环境；甲基化数据需用 GEO 公开数据集；不需要自有数据即可试跑部分模块）
- **可做成什么：** 内容拆解 / 资料库条目 / 衰老时钟方法对比表 / 试跑教程
- **可交付物：** 「主流甲基化衰老时钟对比表」（Horvath / GrimAge / DunedinPACE 等）、资料库条目、公众号选题
- **最低成本验证：** 今天只读 README，整理出该库支持的衰老时钟名单，做一张「常见衰老时钟方法一览表」
- **二次开发路径：** 衰老时钟方法导航页 → 接入 GEO 公开数据做示例 → 长期沉淀为「衰老生物标志物工具库」栏目
- **售后或合规风险：** 中
- **合规边界：** 只写「表观遗传学研究方法观察」，不写「可用于预测个人寿命」或「能诊断衰老疾病」；甲基化检测商业化部分只做信息汇总，不推荐具体检测服务
- **今天最小动作：** 打开 README，列出 3 种支持的衰老时钟，整理一张「衰老时钟方法名称 / 数据来源 / 预测目标」的简表

## 值得观察

**1. EntroPath（流形学习方法）**
方向是单细胞/多组学数据的几何嵌入，理论上可用于衰老细胞状态分析，但当前 README 和应用场景未直接指向衰老数据。需等待更多应用案例或衰老数据集接入案例出现后再考虑内容化。
暂不动原因：技术门槛高，目标鱼塘不清晰，无直接可交付内容线索。

**2. 乳腺钙化分类 CAD 系统论文（多站点域适应）**
该论文展示了深度学习在乳腺癌诊断中的跨站点迁移能力，与衰老领域的「癌症风险 + 早筛」话题相关。但当前无公开代码库，内容化需等论文代码或数据集开放。
暂不动原因：无可试跑代码，内容拆解需等代码开源或更多技术细节披露。

**3. TMF-RSE 肺部严重程度评分框架**
三模态融合的肺病严重程度量化，潜在可用于老年肺健康监测内容化。但当前无公开代码，且肺病严重程度评分偏临床，合规风险中等。
暂不动原因：无代码可试跑，临床表述需谨慎，内容化门槛较高。

**4. Vertex 收购 Crinetics / Novartis 收购 Myricx Bio 产业动向**
两笔大型制药并购涉及罕见病管线和 ADC 肿瘤药物，间接反映大药企在衰老相关疾病（内分泌、癌症）的布局加速。可作为「长寿产业资本动向」月报素材收藏。
暂不动原因：与当前工具/内容交付优先级不符，适合做产业观察背景资料，不适合单独开发。

## 今天别碰

**1. TMF-RSE / 乳腺 CAD 论文的直接商业化解读**
两篇论文涉及癌症诊断和肺病严重程度评分，属于高度临床敏感领域。无代码、无数据、无监管资质，任何「可用于诊断」「可提高检出率」的表述均属高风险合规红区，今天不要做内容或工具开发。

**2. 基于 3D-ResNet 脑龄模型的「个人脑龄检测」服务包装**
White Matter Brain Age 的代码需要 MRI 数据，普通用户无法自行获取；将其包装成「帮你测脑龄」服务涉及医疗器械和诊断合规问题，今天绝对不要碰服务化方向，只做内容科普。

**3. 甲基化衰老时钟的商业检测推荐**
IBAR-ROGEN/Aging 是研究工具，不是消费级检测产品。推荐具体商业甲基化检测服务（如 TruDiagnostic、Elysium 等）需要独立的合规审查和产品信息核实，今天只整理方法，不推荐服务。
