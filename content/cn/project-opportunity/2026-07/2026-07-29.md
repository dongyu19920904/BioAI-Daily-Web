## 今日优先项目

### 1. NeuroBloom — 多发性硬化纵向认知监测平台

这是一个开箱即用的认知任务网页平台，覆盖 6 个认知域、35 个自适应任务，并内置数字生物标记提取。对「AI 生命延续学」方向而言，它是认知衰退监测赛道里少见的可直接试跑的开源工具，且界面和代码都相对轻量（Svelte 构建）。

- **证据来源：** [GitHub — Adit-Mugdha-das/NeuroBloom](https://github.com/Adit-Mugdha-das/NeuroBloom)
- **可信度：** 中（stars 少，但 README 描述具体，功能边界清晰，发布时间 2026-07）
- **目标鱼塘：** 长寿内容读者、照护者、健康管理从业者、神经健康科普自媒体
- **它解决什么问题：** 认知监测工具要么昂贵、要么只有专业机构能用；这个平台免费、开源、支持中文以外的双语，提供了一个可实际操作的认知评估入口
- **试跑门槛：** 低（Svelte 前端，npm/node 环境，跑本地 dev 服务即可看到界面）
- **可做成什么：** 试跑教程 / 工具导航 / 内容拆解 / 资料库条目
- **可交付物：** README 试跑笔记、认知测试截图对比、「6 大认知域是什么」科普图文、工具导航条目
- **最低成本验证：** 今天克隆仓库 → `npm install` → `npm run dev` → 截图主界面 → 写 3 条要点（测了什么/怎么跑/适合谁用）
- **二次开发路径：** ① 做成「免费认知自测工具导航」专栏条目；② 结合可穿戴数据做「日常认知-睡眠-活动」关联内容；③ 照护者使用场景的小红书/公众号选题
- **售后或合规风险：** 中
- **合规边界：** 只写「信息整理与工具观察」，不写「可诊断认知障碍」或「替代医学评估」；强调这是研究/教育工具，不是临床诊断工具
- **今天最小动作：** 克隆本地试跑 → 截一张认知任务界面 → 写一条小红书选题：「开源免费！可以在家做的认知监测工具长什么样？」

### 2. Epigenetic Clock Reasoning Bench — 表观遗传时钟推理评测集

这是一个针对 LLM 在表观遗传时钟领域推理能力的评测基准，方向精准命中「生物衰老时钟」这个长寿赛道核心议题。虽然 stars 为 1，但它代表一个清晰的研究线索：LLM 能否合理推理生物年龄？这个问题本身就是极好的内容选题。

- **证据来源：** [GitHub — varunnair1234/Epigenetic-Clock-Reasoning-Bench](https://github.com/varunnair1234/Epigenetic-Clock-Reasoning-Bench)
- **可信度：** 中（新仓库，stars 极少，但方向和命名高度垂直）
- **目标鱼塘：** 长寿内容读者、科研学习者、独立开发者（对「AI × 衰老评估」感兴趣的人群）
- **它解决什么问题：** 目前缺乏系统评测 LLM 在生物年龄/表观遗传时钟领域推理质量的工具；这个 bench 是填补空白的尝试
- **试跑门槛：** 中（Python，需要理解表观遗传时钟基础概念，依赖项未知，需先看 README）
- **可做成什么：** 内容拆解 / 资料库条目 / 「什么是表观遗传时钟」科普系列入口
- **可交付物：** README 阅读笔记、「表观遗传时钟是什么」3 条要点、LLM 生物年龄推理能力对比选题
- **最低成本验证：** 今天读 README → 记录 bench 包含哪些题目类型 → 整理成一张简表（题型 / 难度 / 数据来源）
- **二次开发路径：** ① 做「AI 能算你的生物年龄吗」内容系列；② 用 bench 数据做 LLM 对比测评内容（GPT vs Claude vs 开源模型）；③ 沉淀成「表观遗传时钟工具地图」资料库条目
- **售后或合规风险：** 低（评测基准，无直接医疗宣称）
- **合规边界：** 写内容时只说「评估 LLM 的推理能力」，不写「可判断真实生物年龄」
- **今天最小动作：** 读 README → 截图项目结构 → 写一条公众号/小红书选题：「AI 能看懂你的表观遗传时钟报告吗？这个开源评测集给了答案」

### 3. 早发性绝经与高血压风险 — 女性衰老健康新研究线索

10 万+ 女性样本的研究发现 40 岁前绝经者高血压风险显著升高，这是「女性衰老加速」赛道里数据扎实、话题性强、可做成科普内容的新线索。

- **证据来源：** [News-Medical — Premature menopause linked to higher risk of developing hypertension](https://www.news-medical.net/news/20260729/Premature-menopause-linked-to-higher-risk-of-developing-hypertension.aspx)
- **可信度：** 高（10 万+ 样本，权威健康媒体报道）
- **目标鱼塘：** 40 岁以上女性读者、长寿健康内容读者、女性健康自媒体受众
- **它解决什么问题：** 女性衰老节点（绝经时间）与心血管风险的关联认知不足，公众缺乏清晰信息
- **试跑门槛：** 低（读原文报道，整理内容即可）
- **可做成什么：** 内容拆解 / 数据科普图文 / 小红书 / 朋友圈选题
- **可交付物：** 一张「绝经年龄 vs 高血压风险」对比表、一条科普朋友圈/小红书文案
- **最低成本验证：** 读完这篇报道 → 整理 3 个数据点 → 写一条选题
- **二次开发路径：** ① 扩展成「女性衰老加速信号」内容系列；② 做「女性衰老生物标记追踪」资料库条目；③ 结合可穿戴血压监测设备做联动内容
- **售后或合规风险：** 中
- **合规边界：** 只写「研究发现关联性」，不写「绝经后必须用某干预手段」；不给出任何诊断或用药建议
- **今天最小动作：** 整理 3 个核心数据 → 写一条小红书选题：「40岁前绝经，心血管风险悄悄升高——10万女性研究数据怎么说」

## 可二次开发方向

**① 「认知监测工具横向对比」资料库**
- 以 NeuroBloom 为起点，横向收录其他开源或免费认知测试工具（MMSE 替代品、Cambridge Brain Sciences 等）
- 可交付物：对比表（工具名 / 测试域 / 是否免费 / 是否可本地跑 / 适合人群）
- 最低成本验证：今天先建一个表格模板，填入 NeuroBloom 一行
- 升级路径：做成「认知健康工具导航」专栏 → 后续加入可穿戴认知数据联动

**② 「表观遗传时钟科普地图」**
- 以 Epigenetic Clock Reasoning Bench 为切入，整理目前主流时钟（Horvath、GrimAge、DunedinPACE 等）的简要说明
- 可交付物：一张「主流表观遗传时钟对比表」（时钟名 / 预测目标 / 数据来源 / 是否开源工具可用）
- 最低成本验证：今天查 3 个时钟的简介，填入表格
- 升级路径：做成「生物年龄检测工具导航」→ 联动商业检测服务资料包

**③ 「女性衰老生物标记追踪」专题系列**
- 结合今日早发性绝经研究 + 可穿戴血压/心率数据，做「女性衰老信号」内容系列
- 可交付物：选题列表（5 条）、第一篇科普草稿纲要
- 最低成本验证：今天先写 5 条选题标题，选 1 条写 500 字纲要
- 升级路径：做成「女性健康衰老周报」栏目 → 吸引照护者 / 健康管理从业者订阅

**④ 脑微结构 MRI 扩散成像科普内容**
- 今日 MRI 扩散时间依赖性论文（Papers.cool）提供了一个「非侵入式神经微结构成像」新视角，可做成「大脑白质老化能看见吗」科普内容

- 最低成本验证：今天读论文摘要，提炼 3 条要点
- 升级路径：做成「神经影像衰老生物标记」资料库条目

- 暂时不动原因：公众科普需要大量转译工作，且无直接可试跑工具，适合作为「神经影像衰老」资料库背景材料，今天先收藏

- 暂时不动原因：报道内容较基础，无具体数据或干预路径，适合等后续论文原文出来再做深度拆解

**④ Argenx 以 22 亿美元收购 Forte Biosciences（免疫学 / 白癜风）**
