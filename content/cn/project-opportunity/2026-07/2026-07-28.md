- **证据来源：** [nopara73/LongevityWorldCup](https://github.com/nopara73/LongevityWorldCup)，GitHub，22 stars，2026-07-27
- **可信度：** 中（开源真实，但平台早期，数据量和活跃度待验证）
- **目标鱼塘：** 长寿内容读者、健身 + 生物黑客爱好者、关注抗衰的中青年用户、独立开发者
- **它解决什么问题：** 把生物年龄测量竞技化、可视化，让普通人有参与感；同时是开源数据收集平台
- **试跑门槛：** 低。C# 项目，但只需浏览 README、跑 demo、截图，不需要深度开发
- **可做成什么：** 内容拆解 / 工具导航 / 试跑教程 / 自媒体选题
- **可交付物：** README 试跑笔记 / 平台介绍对比表 / 小红书/公众号选题草稿 / 资料库条目
- **最低成本验证：** 今天打开 GitHub，读 README，截图项目主界面，整理「生物年龄竞技平台是什么」3 条要点

### 2. Gladyshev-Lab/tAge — 转录组生物年龄预测 R 包

Gladyshev 实验室是长寿领域的顶级实验室，这个 R 包从基因表达数据预测生物年龄，是 biomarker 方向高质量工具。即便不跑代码，光整理「什么是转录组生物年龄」就是很好的科普材料。

- **证据来源：** [Gladyshev-Lab/tAge](https://github.com/Gladyshev-Lab/tAge)，GitHub，23 stars，2026-07-24
- **可信度：** 高（Gladyshev Lab 在生物老年学领域有高影响力发表记录）
- **目标鱼塘：** 生物老年学研究学习者、基因检测行业从业者、长寿科普内容读者、有 R 基础的独立开发者
- **它解决什么问题：** 用基因表达数据（RNA-seq/microarray）计算转录组生物年龄，是研究和产品化 biomarker 的上游工具
- **试跑门槛：** 中。需要 R 环境和基因表达数据，但 README 试读和概念整理门槛低
- **可做成什么：** 内容拆解 / 数据集整理 / 试跑教程 / 文献地图条目
- **可交付物：** 「转录组生物年龄 vs DNA甲基化年龄 vs 蛋白质组年龄」对比表 / README 笔记 / 资料库条目
- **最低成本验证：** 今天只读 README，整理「tAge 是什么、输入什么数据、输出什么结果」3 条要点，做一张生物年龄计算方法对比表
- **二次开发路径：** ① 做「生物年龄计算方法大全」资料库 ② 写教程：「不懂 R 也能看懂的转录组年龄是什么」③ 对比 tAge / Horvath / GrimAge / DunedinPACE 等主要方法的适用场景
- **售后或合规风险：** 低（科研工具，不涉及临床诊断）
- **合规边界：** 所有表达都指向「研究工具」「参考指标」，不写「可用于诊断衰老疾病」
- **今天最小动作：** 读 README → 整理 3 条要点 → 开始做「主要生物年龄计算方法对比表」草稿（tAge / Horvath Clock / GrimAge / DunedinPACE）

### 3. 帕金森汗液贴片可穿戴监测新闻 — 可穿戴数据观察线索

UCSD 开发的无电池指尖汗液贴片，能实时追踪左旋多巴药物浓度，精度媲美血液检测。这是可穿戴生物标志物监测的重要硬件线索，适合做健康硬件观察专栏内容。

- **证据来源：** [GEN：Parkinson's Disease Medication Monitored with Fingertip Sweat Patch](https://www.genengnews.com/topics/translational-medicine/parkinsons-disease-medication-monitored-with-fingertip-sweat-patch/)，2026-07-27
- **可信度：** 高（UCSD 工程团队，有实验数据对比）
- **目标鱼塘：** 可穿戴健康硬件关注者、神经退行性疾病照护者、健康管理从业者、长寿科技内容读者
- **它解决什么问题：** 解决帕金森患者药物浓度监测只能靠血液检测（有创、不连续）的痛点，实现无创连续监测
- **试跑门槛：** 低（纯内容整理，无需跑代码）
- **可做成什么：** 内容拆解 / 硬件观察笔记 / 可穿戴数据分析选题 / 资料库条目
- **可交付物：** 「汗液生物标志物可穿戴设备」资料库条目 / 选题草稿 / 新闻要点摘录
- **最低成本验证：** 今天收藏原文，整理「这个贴片解决什么问题、精度如何、距离商业化多远」3 条要点
- **二次开发路径：** ① 做「汗液/皮肤生物标志物可穿戴设备追踪表」② 扩展成「神经退行性疾病可穿戴监测工具导航」③ 长期跟踪类似硬件作为周报栏目
- **售后或合规风险：** 低（纯新闻内容整理）
- **合规边界：** 表达为「研究阶段成果观察」，不写「可购买使用」「推荐患者使用」
- **今天最小动作：** 收藏原文 → 写 3 条要点摘录 → 起草一条公众号/小红书选题：「手指贴片替代抽血——帕金森可穿戴监测新进展」

- **证据来源：** [News-Medical：Can Alzheimer's genes predict who becomes a SuperAger?](https://www.news-medical.net/news/20260728/Can-Alzheimers-genes-predict-who-becomes-a-SuperAger.aspx)，2026-07-28
- **可信度：** 中（摘要信息，需阅读原研究，但 News-Medical 来源可靠）
- **目标鱼塘：** 关注认知衰老的中老年读者和家属、长寿内容读者、健康科普内容消费者
- **它解决什么问题：** 揭示长寿认知的多因素本质，破除「基因决定论」，给生活方式干预留空间
- **试跑门槛：** 低（纯阅读整理）
- **可做成什么：** 内容拆解 / 公众号选题 / 小红书推文
- **可交付物：** 选题草稿 / 要点摘录 / 科普图文框架
- **最低成本验证：** 今天读原文，整理「什么是 SuperAger、基因解释多少、还有哪些因素」3 条要点
- **二次开发路径：** ① 做「SuperAger 研究文献地图」② 写系列：「比基因更重要的长寿大脑保护因素」③ 结合 tAge 等生物年龄工具做联动内容
- **售后或合规风险：** 低

**3. 碘与免疫系统综述新闻**

- 暂不动的原因：结论不够明确（「可能影响」），写内容时容易被质疑，且甲状腺/免疫补充剂话题合规敏感
- 建议：收藏备用，如果后续有更明确的临床研究再跟进

**4. EEG Foundation Models Benchmark 论文**
对 6 个 EEG 基础模型在临床任务（含韩国痴呆数据集 CAUEEG）上的压力测试，发现传统特征在某些任务上仍优于预训练模型，结论有科普价值。
- 暂不动的原因：论文本身是方法论批评，内容化需要一定 AI + 神经科学背景，受众范围较窄；建议结合 EEG 项目追踪表一起处理
- 建议：录入 EEG 项目追踪表，作为「AI 模型在痴呆检测中的局限性」内容的引用来源

## 今天别碰

**1. 儿科骨科 IR 影像 + AI 论文（红外成像替代 X 光）**
技术框架复杂（五种红外波段 × 深度学习），涉及儿科临床诊断，合规风险高，距离可用产品遥远，内容化需要大量医学背景，不适合当前方向。

**2. 具身机器人操作数据金字塔论文**
与 AI 生命延续学方向无直接关联，是机器人学和多模态 AI 领域的方法论论文，受众完全不同，今天不应占用精力。

**3. 任何将生物年龄工具包装成「衰老诊断」或「抗衰疗效」的内容方向**
tAge、LongevityWorldCup 等工具都是参考性科研工具，今天的素材中没有任何已通过临床验证的抗衰干预效果证据。如果因为「看起来高级」就写成「科学证实的抗衰方法」，会产生医疗宣称风险，应坚决避免。
