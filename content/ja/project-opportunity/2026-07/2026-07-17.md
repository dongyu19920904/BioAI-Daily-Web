## 今日优先项目

### 1. gangchen/epiage-skill — 24个表观遗传衰老时钟，可本地运行的 Agent 技能包

这是今天素材里试跑门槛最低、内容拆解价值最高的项目。24个主流衰老时钟（GrimAge、PhenoAge、Horvath 等）打包成一个可离线安装的 Python 技能，依赖只有 pandas+numpy，不需要 GPU 或云端 API。对"衰老生物钟"这个内容方向来说，这是难得的能真正跑起来、截图、写笔记的素材。

- **证据来源：** https://github.com/gangchen/epiage-skill（GitHub，2026-07-12 发布，Python）
- **可信度：** 中（stars 仅 2，项目新，需本地验证功能是否完整，但依赖轻、README 可快速核查）
- **目标鱼塘：** 长寿内容读者、生物信息学习者、独立开发者、健康管理从业者中对"生物年龄检测"感兴趣的人群
- **它解决什么问题：** 把分散在学术代码库里的衰老时钟算法统一打包，让非专业用户也能本地调用，而不必自己拼接各论文的代码
- **试跑门槛：** 低。Python + pip install，无 GPU 需求，无需申请数据集，可用公开示例数据或构造假数据测试接口
- **可做成什么：** 试跑教程 / 内容拆解 / 工具导航条目 / 资料库词条（24个时钟各是什么、测什么、怎么解读）
- **可交付物：** README 试跑笔记 / 24个衰老时钟对比表 / 小红书/公众号选题草稿 / 资料库条目
- **最低成本验证：** 今天 clone 仓库 → 安装依赖 → 跑通示例 → 截图 → 整理3条要点（"这24个时钟分别测什么、哪个最常被研究引用、普通人用不用得上"）
- **二次开发路径：** ① 做成"衰老时钟工具导航"资料库页面；② 写系列教程：每个时钟一期拆解；③ 包装成轻量 web demo，输入甲基化数据输出生物年龄估算（需注意数据获取门槛）；④ 做成 AI 助手的知识模块，回答"我的 GrimAge 比实际年龄高X岁意味着什么"
- **售后或合规风险：** 中
- **合规边界：** 只写"这是研究工具，用于学习表观遗传时钟算法原理"，不写"可以测你的真实生物年龄"，不提任何干预建议。结果解读只做信息科普，不做个人诊断
- **今天最小动作：** `git clone` → `pip install pandas numpy` → 跑通一个时钟的示例调用 → 截图 → 写"今天跑通了24个衰老时钟工具包，分享3条发现"朋友圈/小红书草稿

### 2. shayanmostafaei/Omics_ADRD_Integrated_Modeling — 多组学+PRS预测阿尔茨海默症，UK Biobank 数据

这是目前素材里学术价值最高、内容拆解空间也最大的项目。把多组学衰老时钟、多基因风险评分（PRS）和机器学习结合起来预测 ADRD，用的是 UK Biobank 公开数据集，代码是 R+Python。对做"认知衰退/痴呆风险"内容方向的账号来说，这个项目可以做成文献地图、方法论拆解、数据集导航等多种内容形式。

- **证据来源：** https://github.com/shayanmostafaei/Omics_ADRD_Integrated_Modeling（GitHub，2026-07-08，R/Python，stars 4）
- **可信度：** 中（方向和方法论可信，但 stars 少、项目新，代码质量需自行核查）
- **目标鱼塘：** 长寿内容读者（痴呆预防方向）、科研学习者、健康管理从业者、照护者社群中关注 ADRD 风险评估的人
- **它解决什么问题：** 把多组学数据整合建模的完整流程（预处理→建模→生存分析→可视化）打包，降低研究复现门槛
- **试跑门槛：** 高。UK Biobank 数据需申请（有门槛），R+Python 双语依赖复杂，不适合今天直接跑数据。但 README 和代码结构今天可以读完
- **可做成什么：** 内容拆解（"多基因风险评分是什么、为什么它比单基因检测更有参考价值"）/ 文献地图 / 方法论科普 / 资料库条目
- **可交付物：** 方法论对比表（组学时钟 vs PRS vs 传统风险因子）/ 资料库条目 / 选题草稿
- **最低成本验证：** 今天只读 README 和代码目录结构，整理3条方法论要点，做一张"ADRD风险预测方法对比表"
- **二次开发路径：** ① 做成"痴呆风险预测方法论科普"系列内容；② 做文献地图（哪些组学特征和 ADRD 相关）；③ 如果后续能获取模拟/公开数据，可做轻量演示
- **售后或合规风险：** 高
- **合规边界：** 严格写"这是学术研究方法整理，不是基因诊断工具，不能用于个人风险判断"。不写任何"测出来就能预防"的表达
- **今天最小动作：** 读 README → 整理方法论3要点 → 做对比表草稿（一行一个方法，列：数据类型/预测目标/可解释性/普通人能用吗）→ 存入资料库

### 3. GPR40受体与胸腺老化——免疫衰老内容选题信号

两篇来自 Lifespan.io 和 News-Medical 的研究报道（2026-07-16）都在说同一件事：靶向 GPR40 受体可以延缓小鼠胸腺退化（thymic involution），而胸腺退化是免疫系统老化的核心机制之一。这是"免疫衰老"内容方向今天最新的研究信号，适合做科普选题，不适合做产品推荐。

- **证据来源：**
  - https://lifespan.io/activating-a-key-receptor-fights-thymic-involution-in-mice/（Aging Cell 期刊，Lifespan.io 报道）
  - https://www.news-medical.net/news/20260716/Researchers-identify-immune-cell-receptor-that-drives-organ-aging-process.aspx（Stanford Medicine 研究）
- **可信度：** 高（同行评审期刊 Aging Cell，Stanford 来源，两家媒体独立报道）
- **目标鱼塘：** 长寿/抗衰内容读者、关注免疫健康的中老年人群、健康管理从业者
- **它解决什么问题：** 解释为什么人老了更容易生病、更难打赢疫苗——胸腺退化是关键机制
- **试跑门槛：** 低。纯内容方向，只需读两篇报道+原始摘要
- **可做成什么：** 科普内容 / 小红书选题 / 公众号推文 / 资料库词条（胸腺/免疫衰老）
- **可交付物：** 一条小红书/朋友圈选题草稿 / 资料库条目"胸腺衰老与免疫系统老化"
- **最低成本验证：** 今天读完两篇报道，写一条选题：「为什么老年人免疫力差？科学家找到了一个新靶点」
- **二次开发路径：** ① 做"免疫衰老"专题资料库；② 跟踪 GPR40 后续临床进展；③ 做"胸腺、T细胞、免疫老化"科普系列
- **售后或合规风险：** 低（纯研究阶段，只做科普，不涉及产品推荐）
- **合规边界：** 写"动物实验阶段，尚无人体临床证据，不代表任何干预有效"
- **今天最小动作：** 读两篇报道 → 写一条选题草稿 → 存入内容库

## 值得观察

**① GodPascal/brain-age-prediction — 从 MRI 估算脑年龄**
- 官方论文代码（Human Brain Mapping 2025），CPU 可跑，Apptainer 容器封装
- 暂时不动的原因：需要真实 T1 加权 MRI 数据，普通用户无法自行获取；Apptainer 容器安装对非Linux用户有门槛；内容价值偏专业，直接拆解科普需要神经影像学背景
- 观察价值：如果"脑年龄检测服务"商业化加速，这个项目可以作为技术背景资料
- 跟踪动作：收藏，等待有 MRI 数据或合作医疗机构资源时再评估

**② BrainPilot 论文 — 自动化脑科学研究 Agent**
- 用 AI Agent 自动化神经科学研究流程，有"防幻觉"和"专家介入节点"设计
- 暂时不动的原因：纯学术框架，无开源代码，商业路径不清晰，复现门槛极高
- 观察价值：如果后续开放代码或工具，可以做成"AI+脑科学研究工具"内容方向的案例
- 跟踪动作：收藏论文链接，追踪是否开源

**③ mateomics/Macaca_mulatta 猕猴脑衰老转录组**
- 灵长类动物脑老化基因表达数据，有完整 RNA-seq 分析流程
- 暂时不动的原因：stars 仅 1，数据来自动物模型，内容拆解需要转录组分析背景，目标鱼塘不清晰（科研读者太窄）
- 观察价值：作为"非人灵长类衰老研究"资料库背景素材
- 跟踪动作：收藏，作为资料库条目备用

**④ 睾酮替代治疗新指南**
- 权威医学学会更新 TRT 临床实践指南（2026-07-16）
- 暂时不动的原因：合规风险高，TRT 是处方医疗干预，任何内容都容易被误读为推荐；读者如果有需求应直接咨询医生
- 观察价值：可作为"男性激素与衰老"科普内容的背景资料，严格保守表达
- 跟踪动作：收藏指南链接，写内容时只做"指南存在、建议在医生指导下评估"的信息性表达

- 目前素材中的所有检测方法（表观遗传时钟、PRS、脑年龄估算）均为研究工具，非临床诊断
- 直接推荐商业检测服务涉及医疗宣称合规风险，在内容平台上容易触发违规
- 表达边界：只写"这是研究方法/学术工具"，不写"测了能知道你的真实年龄/风险"
