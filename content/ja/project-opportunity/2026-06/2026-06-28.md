## 今日优先项目

### AgeLens-AI — 生物年龄预测轻量 HTML 工具

一个基于生活方式和健康因素预测生物年龄的 HTML 项目，代码量小、门槛极低，适合作为内容拆解素材或轻量 demo 改造起点。星数虽低（2 stars），但方向直接命中「生物年龄」这个高热度长寿内容话题。

- **证据来源：** [deepikaranibm/AgeLens-AI](https://github.com/deepikaranibm/AgeLens-AI)，GitHub Trending，2026-06-22
- **可信度：** 低（新项目，stars 极少，功能未经验证，需亲自读 README 确认）
- **目标鱼塘：** 长寿内容读者、关注健康数据的自媒体受众、对"测生物年龄"感兴趣的普通用户
- **它解决什么问题：** 提供一个可本地运行的生物年龄估算界面，让用户输入生活方式数据得到参考结果
- **试跑门槛：** 低 — 纯 HTML，无需安装依赖，浏览器直接打开即可
- **可做成什么：** 试跑教程 / 内容拆解 / 轻量 demo 截图对比
- **可交付物：** README 试跑笔记、截图、3 条要点、一张"它能测什么 / 不能测什么"对比表
- **最低成本验证：** clone 或下载 zip，打开 index.html，截图，整理 3 条功能说明
- **二次开发路径：** 改造成微信 H5 或小红书截图素材；或补充"生物年龄指标科学依据"资料卡；中期可接入真实 biomarker 数据（如 Oura/Apple Health 导出）
- **售后或合规风险：** 中 — 不能宣称"测出真实生物年龄"或"指导医疗决策"
- **合规边界：** 只写"基于生活方式的参考估算工具，非医学诊断，不替代体检和医生建议"；拆解内容中明确标注这是研究性/娱乐性工具
- **今天最小动作：** 下载 zip → 浏览器打开 → 截图 → 写一条小红书选题："我用 AI 测了自己的生物年龄，结果比实际小 X 岁？来看它到底测了什么"
