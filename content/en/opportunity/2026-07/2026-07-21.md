## 今日主推

### 机会一：「边缘端 EEG 痴呆检测」——可穿戴认知健康内容选题 + 工具观察清单

今天这篇论文把"痴呆 AI 筛查"从云端推向了可穿戴边缘设备，是一个非常明确的内容信号。照护家属和抗衰爱好者正在寻找"在家能做的认知监测"答案，这篇论文可以成为一篇高传播的科普选题，也能变成一张"现有 EEG/脑波可穿戴设备横向对比表"的起点。

- **证据来源**：论文《Differentiable Logic Gate Networks for Low-Latency EEG Classification on Edge Devices》，Papers.cool / arXiv:2607.18149，2026-07-20
- **可信度**：中（学术论文，鼠类/数据集验证，尚未商业落地，不能写成"已可用产品"）
- **目标鱼塘**：①有痴呆家属的照护者（焦虑买单型）；②关注可穿戴设备的抗衰爱好者；③做健康科技内容的创作者
- **痛点和付费理由**：照护家属最怕"没有早期预警"，愿意为"家用认知监测工具清单/教程"付费；可穿戴用户想知道哪款设备真的能测认知功能
- **可交付物**：①公众号/小红书科普文"AI 可以在耳机里检测老年痴呆了？"；②可穿戴 EEG 设备横向对比表（Muse、Neurosity、Dreem 等现有产品）；③"家用认知监测入门资料包"（Notion 或飞书）
- **适合做什么**：内容选题 + 数据整理（设备对比表）+ 项目跟进（跟踪该论文后续商业化）
- **最低成本验证**：今天写一条小红书/公众号标题测试点击率，例如"普通人能在家监测老年痴呆了吗？这个 AI 芯片让可穿戴设备做到了"——观察 24 小时互动数据
- **复购或升级路径**：免费科普文 → 低价资料包（可穿戴认知检测设备清单 + 使用教程） → 社群（照护家属圈子）→ 轻咨询（帮家属选设备和建立监测流程）
- **售后或合规风险**：中
- **合规边界**：不能写"EEG 可以诊断痴呆"、"买了这个设备就能预防老年痴呆"。只能写"研究中的技术方向"、"信息观察"，帮读者了解研究进展，不能给出诊断建议
- **今天最小动作**：写一条小红书草稿，标题测试，配图用论文里的设备示意图

### 机会二：「脑老化生物标志物」——GitHub 项目复盘 + 大脑年龄内容选题

公开代码的脑老化解剖模型（161 名受试者，10-80 岁，机器学习识别老化生物标志物）是一个非常适合做"大脑生物年龄"内容的具体素材。这个方向在抗衰圈和照护圈都有持续流量，而且切入点清晰：你的大脑老了几岁？

- **证据来源**：GitHub 项目《SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age》，https://github.com/SaraYCano/Antomical-modelo-of-the-whole-brain-associated-with-age，2026-06-14
- **可信度**：中（学术研究项目，数据来自健康受试者，研究阶段，非商业产品）
- **目标鱼塘**：①抗衰爱好者（关注"生物年龄"概念）；②做科学内容的创作者；③想了解大脑老化检测的中产家庭
- **痛点和付费理由**：抗衰爱好者对"生物年龄 vs 实际年龄"有强烈好奇心，愿意为"大脑年龄检测指南"类资料包付费；照护家属想知道家人大脑老化到了哪个阶段
- **可交付物**：①科普文"你的大脑老了几岁？科学家用 AI 测出来了"；②"大脑生物年龄检测方法汇总"资料包（整理现有 MRI、EEG、认知测试等维度）；③Notion 资料库雏形（收录公开数据集和工具链接）
- **适合做什么**：内容选题 + 资料库整理 + 项目跟进
- **最低成本验证**：把 GitHub 项目读一遍，整理成一张"大脑老化研究方法对比表"（MRI / EEG / 认知评估 / 血液标志物），发一条朋友圈或社群消息看反应
- **复购或升级路径**：免费对比表 → 低价资料包（大脑健康检测指南） → 社群/会员（持续更新研究进展）→ 项目陪跑（帮小机构或个人建立认知监测流程）
- **售后或合规风险**：中
- **合规边界**：不能写"这个方法可以测出你的大脑年龄"（需要专业设备和医疗机构）。只能写"研究人员用了哪些方法"，不能给出个人诊断建议
- **今天最小动作**：Fork 或 Star 该项目，整理一张方法对比表，发朋友圈测试反应

## 今天别碰

**1. 干细胞外泌体（Exosomes）治疗肝病**
- 为什么别碰：仅鼠类实验结果，距离人体临床应用距离极远。如果写成"干细胞可以治肝病"会有重大合规风险和虚假宣传风险。即便写成科普，受众对"鼠类实验"的转化价值感知度低，转化率差。
- 风险：高（医疗虚假宣传风险）

**2. LLM 生物安全风险论文（Intern-BioBreaker）**
- 为什么别碰：该论文讨论 LLM 在生物武器领域的安全风险，内容敏感，与目标读者（抗衰/健康）关联度极低，容易引发平台审核问题。
- 风险：高（内容合规风险）

**3. 罕见神经病变（特定脑区损伤机制）**
- 为什么别碰：受众极小，科研背景太强，无法落到具体交付物，不适合今天追。读者看了也不知道能做什么，内容转化率接近零。
- 风险：低，但投入产出比极低
