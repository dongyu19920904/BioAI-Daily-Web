### 本地生物标记物追踪工具线索：整理成"AI生物年龄工具导航"资料包

今天出现了两个方向一致的开源项目：ai-2070/biomarker-tracker 描述支持血检记录、PhenoAge生物年龄计算和 AI 助手引用查询；gangchen/epiage-skill 打包了24种表观遗传衰老时钟为可安装的离线 Python 技能。两者功能描述与国内长寿爱好者和可穿戴用户的信息需求方向相符，适合整理成导航类内容，但功能实现、许可证、数据入口均未核查。

- 证据来源：[ai-2070/biomarker-tracker](<https://github.com/ai-2070/biomarker-tracker>)（GitHub项目，stars:2，TypeScript，最近活动2026-11-24）；[gangchen/epiage-skill](<https://github.com/gangchen/epiage-skill>)（GitHub项目，stars:4，Python，最近活动2026-11-19）
- 可信度：低。两个项目均为极低 star、描述未经核查，功能是否可用、许可是否允许商用均不明确。
- 目标鱼塘：关注生物年龄检测的长寿爱好者；购买过血检套餐但不知道怎么解读数据的用户；正在搭建 AI 健康工具的独立开发者。
- 痛点和付费理由：付费意愿待验证。假设性痛点是这类用户手上有血检数据，但缺乏工具将数字与"生物年龄"概念连接；市面上付费平台价格较高且不支持本地化。是否会为免费导航资料付费、付多少，目前没有询价材料支撑。
- 可交付物：工具导航对比表（1-2页 Notion 或飞书文档），列出现有开源生物年龄工具的功能描述、依赖环境、已知局限、是否可本地运行，不承诺任何计算结论。
- 适合做什么：内容选题（工具导航文章）、数据整理（工具对比表格）
- 最低成本验证：今天打开两个 GitHub 仓库，记录 README 是否存在、安装依赖是否可读、许可证类型、有无 issue/PR 活跃迹象。整理成一张5行对比表，发到目标群或账号，观察是否有人点开链接或追问。
- 成功指标：7天内发布的导航内容获得至少5个真实问题（不是点赞），或至少1人询问如何使用或是否有中文教程。
- 停止条件：发布后7天无任何问题或询价；或核查后发现两个项目均无法正常安装、无许可证许可商用，停止投入工具类产品开发，改为纯内容方向。
- 复购或升级路径：导航资料包（免费或低价）→ 安装教程（付费文章或会员）→ 帮人跑通工具的轻咨询服务（待有需求再做）
- 售后或合规风险：中。工具计算的"生物年龄"是研究性指标，不是诊断结论；导航文章中必须明确说明这些工具未经临床验证，不能用于个人健康判断或医疗决策。
- 合规边界：不能写"用这个工具测出你的真实年龄"；只能写"这是研究者用的衰老时钟算法，用于记录和参考，不替代医疗检测"。
