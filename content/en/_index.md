## **🔥 Today's Top 7 Highlights**

### 1. Hypothalamic Neuron Cilia Length Affects Whole-Body Metabolism and Caloric Restriction Outcomes

According to [a report from Lifespan.io](https://lifespan.io/how-some-neuronal-cilia-may-affect-the-whole-body/), researchers found that cilia on hypothalamic neurons — those antenna-like structures that cells extend outward — shorten with age, and declining NAD+ levels are the direct culprit. In vitro experiments showed that supplementing NAD+ precursors or inhibiting CD38, the enzyme that consumes NAD+, was enough to get cilia growing again. The CHMP4B protein inside cilia cycles back to lysosomes to keep them intact, and that process breaks down when NAD+ runs low. Critically, when researchers knocked out cilia growth genes using silencing RNA, caloric restriction in 24-month-old mice stopped improving some metabolic markers — which means the cilia on these specific neurons are a *required* piece of the caloric restriction puzzle. 🧬 The work has been published in a peer-reviewed journal, but it's mice-only for now, and whether human hypothalamic cilia work the same way is still an open question.

### 2. RFD4-Proteina — Nvidia and UW's Open-Source Protein Design Model — Just Dropped

According to [a report from GEN](https://www.genengnews.com/topics/artificial-intelligence/nvidia-uw-institute-for-protein-design-unveil-open-source-protein-design-ai-model/), RFD4-Proteina is a new open-source generative model built on the Nvidia BioNeMo platform, released through a collaboration between the UW Institute for Protein Design — led by Nobel laureate David Baker — and Nvidia. The model can simultaneously optimize protein sequences, structures, and their interactions with other molecules. Lab tests across four task types — protein binding, small molecule binding, enzyme scaffolding, and DNA binding — show RFD4-Proteina hits a 5–10x higher design success rate than baseline methods, while also generating results 5–10x faster. 🚀 It's available under a BSD-3 license via Amazon Bio Discovery, Hugging Face, Google Cloud, and other platforms. Baker says it'll help design proteins for drug discovery and enzymes that can degrade pesticides — though the road from computational design to lab validation still takes time.

### 3. Cryo-EM and an AI-Designed Scaffold Reveal How Andes Hantavirus Binds Human Cells

According to [a report from GEN](https://www.genengnews.com/topics/infectious-diseases/cryo-em-and-ai-designed-scaffold-reveal-how-andes-hantavirus-binds-cells/), a research team used cryo-EM to resolve the binding structure between the Andes virus spike protein and the human receptor protocadherin-1 (PCDH1) at near-atomic resolution. Andes virus is the only hantavirus known to spread person-to-person, and it can cause a fatal pulmonary syndrome. The team found that four Gn glycoprotein subunits on the viral surface form a deep pocket, into which PCDH1 inserts in a slender shape — most antibodies are simply too bulky to get in there. An AI-designed scaffold was used to stabilize this tetrameric complex. Mutagenesis experiments confirmed that three Gn loops are involved in binding, and the researchers even managed to transfer this binding capability onto an Old World hantavirus. 🔬 The paper is out in *Nature*, and the authors think designing slender molecules to block that deep pocket could be a viable antiviral strategy — though no drug candidates exist yet.

## **🧪 Cutting-Edge Research**

### Trion-1: A Diffusion Language Model That Unifies Language, Protein Sequences, and Structure

The [arXiv preprint](https://papers.cool/arxiv/2610.31215) introduces Trion-1, the first natively unified multimodal protein diffusion language model (dLLM). It represents sequences, structures, and natural language in a single unified discrete token space, and replaces strict left-to-right generation with bidirectional or semi-bidirectional interactions — enabling global residue communication and long-range contact modeling. This design unifies six core capabilities in one shot: folding, inverse folding, sequence understanding, structure understanding, sequence design, and structure design, while preserving the instruction-following ability of general-purpose LLMs. In benchmarks, Trion-1 hits a TM-score above 0.8 with a single sample (TM-score measures how closely a predicted structure matches the true one; above 0.5 means the same fold), matching what existing tri-modal models achieve with 200 samples. On sequence understanding tasks it scores 62.37%, putting it close to Claude Opus 4.7. 📄 This is a preprint, not yet peer-reviewed; code and model weights are available from the paper link.

### A Visual Grounding Benchmark for Evaluating Multimodal LLMs on Retinal OCT Imaging

The [arXiv preprint](https://papers.cool/arxiv/2610.31205) introduces RetinaGroundBench, the first benchmark for visual grounding of biomarkers in retinal optical coherence tomography (OCT) — the most commonly used imaging technique in ophthalmology, capable of showing the layered structure of the retina. The benchmark contains 815 B-scan images annotated by ophthalmologists with 4,537 bounding boxes covering 13 biomarkers across 8 diseases. The study evaluated 27 open-source multimodal LLMs (0.8B–38B parameters) and found visual grounding is far from solved: the best general-purpose model hits only 23.7% macro F1, with consistently low recall — even though accuracy on biomarker presence/absence questions can reach 73%. RetGrounder (8B), fine-tuned with OCT-specific strategies by the authors, pushes F1 up to 33.9%, a relative improvement of 43%. 👁️ This is a preprint; code and model are available from the paper, but clinical validation hasn't been done yet.

## **⌘ Top Open-Source Projects**

### ADAMMA-CDHI-ETH-Zurich/CosinorAge: A Circadian Rhythm-Based Biological Age Prediction Package

[CosinorAge](https://github.com/ADAMMA-CDHI-ETH-Zurich/CosinorAge) is a Python package implementing cosinor-based biological age prediction. Circadian rhythms — the body's roughly 24-hour physiological cycles — shift in amplitude and phase as we age, making them useful as aging biomarkers. This tool is a good fit for researchers who need to estimate biological age from time-series physiological data like body temperature or activity levels. The repo includes code for model training and prediction, though the README doesn't specify input data format, pretrained models, or validation datasets — so check the docs or example scripts before diving in. ⭐ 13 stars, last active October 23, 2026; license isn't shown on the GitHub page and needs a closer look.

### JesperBoman/Butterfly_DNAm_age: Scripts for Training Epigenetic Clocks

[Butterfly_DNAm_age](https://github.com/JesperBoman/Butterfly_DNAm_age) provides scripts for training epigenetic clocks — tools that predict biological age from DNA methylation (DNAm) patterns. While most epigenetic clocks are built for humans or mammals, this project focuses on butterflies, making it a useful reference for aging research in non-model organisms. 🦋 The repo includes data preprocessing and model training pipelines, and is a good fit for teams studying insect lifespan or comparing aging mechanisms across species. The README doesn't detail dependency environments, methylation data sources, or clock prediction accuracy, so you'll want to dig into the code comments. 1 star, last active October 23, 2026; license and release status still need to be verified.
