## 可二次开发方向

### 1. 蛋白质组学衰老检测工具对比表

- **最低成本验证**: 今天查阅 3-5 篇相关论文和官方文档,整理成 3 列对比表(工具名称/数据类型/个人可得性)

### 2. GitHub 衰老计算项目监测页
- **可交付物**: 简单的 HTML 页面或 Google Sheets,每周自动抓取 GitHub 上新增的 aging/longevity/biomarker 相关项目,记录 stars、最近更新、许可证和 README 完整度
- **最低成本验证**: 今天手动整理 5-10 个项目的基本信息(repo URL、创建日期、语言、star 数、许可证)
- **后续升级路径**: 用 GitHub Actions 定时抓取并生成周报;过滤出"最近 7 天活跃 + README 完整 + 开源许可"的项目,推送到 Telegram/Discord/邮件列表;可沉淀成长期资料库和周报栏目

### 3. 线粒体转移研究文献地图
- **可交付物**: 基于 2026-09-22 Lifespan.io 报道的线粒体转移研究,整理相关论文、临床试验和动物实验的时间线和研究阶段
- **最低成本验证**: 今天查找原始论文 DOI,确认研究对象(小鼠/Friedreich's ataxia 模型)、干预方法(免疫细胞移植)和主要结论;写成 3 条要点 + 1 张时间线图
- **后续升级路径**: 扩展成"线粒体医学研究地图",包含线粒体转移、线粒体替代疗法、mtDNA 编辑等方向的论文、临床试验和商业公司;可服务科研学习者和投资观察者
- **合规边界**: 明确标注"动物实验阶段,人体有效性未验证",不宜宣传为现成抗衰手段

### 4. 可穿戴数据 + 生物年龄计算器清单
- **可交付物**: 整理现有的开源生物年龄计算工具(如 PhenoAge、DNAmAge、Morgan Levine's calculator),说明输入数据类型(血液生化/可穿戴数据/问卷)、计算方法和数据隐私要求
- **最低成本验证**: 今天找 3-5 个计算器,试跑一次(如果需要输入数据,用公开数据集或匿名样本),截图并记录输入字段和结果解释

## 值得观察

### 1. OpenLongevityLab
- **暂时不动原因**: 项目创建仅 1 天,无 releases、贡献者或运行示例,README 只有简短描述,今天无法验证其"计算基础设施"是否可用
- **观察条件**: 等待首个 release、完整 README、示例代码或至少 10 stars;如果后续提供可运行的 biological age calculator 或 aging biomarker dashboard,可重新评估
- **可能价值**: 如果项目持续更新并提供清晰的数据输入/输出接口,可做成试跑教程或资料库条目

### 2. ctai 器官特异性生物年龄平台
- **暂时不动原因**: 基于 SomaScan 蛋白质组学数据,个人和小团队难以获取(需商业合作或科研机构授权);OrganAge 模型的训练数据和验证方法未在 repo 中说明
- **观察条件**: 等待项目提供示例数据集、预训练模型或 Docker 容器;或者作者公开 OrganAge 模型的论文引用和验证结果
- **可能价值**: 如果项目后续开放示例数据或提供"仅用公开血液生化指标"的简化版本,可做成教程或对比表;但面向 C 端的器官年龄检测服务涉及医疗宣称,不适合独立开发者

### 3. 线粒体转移研究(Lifespan.io 报道)
- **暂时不动原因**: 当前仅有动物实验(Friedreich's ataxia 小鼠模型),人体有效性、安全性和临床路径未明确;不适合立刻做成产品或服务
- **观察条件**: 跟踪相关临床试验注册(ClinicalTrials.gov)、后续论文发表和监管审批进展
- **可能价值**: 可整理成"线粒体医学研究动态"资料库条目,服务科研学习者;或做成"罕见病基因治疗观察"选题,但必须明确标注研究阶段和临床距离

### 4. AAV 基因治疗开发(GEN 新闻)
- **暂时不动原因**: AAV(腺相关病毒)开发属于专业生物技术领域,设备、试剂和合规门槛极高,不适合独立开发者或内容创作者直接操作
- **观察条件**: 如果后续出现"AAV 基因治疗临床试验数据库"或"基因治疗公司投资观察"等可整理的资料,可重新评估
- **可能价值**: 可做成"基因治疗技术科普"或"AAV vs 其他载体对比表",服务科研学习者和投资观察者,但不涉及实际开发

## 今天别碰

### 1. Pulse AI Health Platform
- **原因**: 项目声称提供"生物年龄计算和健康风险预测",但 GitHub repo 无许可证说明、无数据来源、无临床验证,直接涉及医疗预测和健康宣称
- **风险**: 如果做成面向 C 端的健康平台,涉及医疗器械监管、数据隐私(GDPR/HIPAA)、误诊责任和售后纠纷;即使仅作为"实验性工具",用户误用后的法律责任不清
- **替代方案**: 如果对"生物年龄计算"感兴趣,优先选择已有论文验证和开源许可的工具(如 PhenoAge、Aging.ai),做成教程或对比表,而不是自建平台

### 2. Western Blotting 数据完整性(GEN 新闻)
- **原因**: Western blotting 属于实验室蛋白检测方法,需要实验设备、试剂和专业操作,不适合独立开发者或内容创作者;新闻主要讨论数据完整性和论文撤稿问题,无直接可操作项目
- **可能误区**: 不要试图做成"Western blotting 数据分析工具"或"抗体选择推荐系统",这些需要深厚的生物化学背景和实验室资源
- **替代方案**: 如果对"科研数据完整性"感兴趣,可整理"撤稿案例分析"或"开放科学工具清单",但不涉及实验操作

### 3. 基于 SomaScan 的个人衰老检测服务
- **原因**: SomaScan 蛋白质组学检测需要商业合作或科研机构授权,个人用户无法直接获取数据;即使拿到数据,将蛋白标志物解读为"器官年龄"或"健康风险"涉及医疗诊断宣称
- **风险**: 数据不可得、商用许可不清、医疗合规重、售后责任不明
- **替代方案**: 可做成"蛋白质组学衰老标志物文献整理"或"SomaScan vs Olink 对比表",服务科研学习者,但不面向 C 端提供检测服务
