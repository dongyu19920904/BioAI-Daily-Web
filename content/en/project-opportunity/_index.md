## 今日优先项目

### pyaging - GPU 优化衰老时钟 Python 工具包

一个整合多种表观遗传衰老时钟算法的 Python 库，用 GPU 加速计算，适合技术内容创作者拆解算法逻辑、对比不同时钟模型或做数据集清洗教程。

- **证据来源**：GitHub 项目 https://github.com/lucascamillomd/pyaging ，2026-10-18 发布，132 stars
- **可信度**：中（代码公开，但算法有效性需参照原始论文，个人健康应用未经临床验证）
- **目标鱼塘**：技术内容创作者、生物信息学习者、衰老研究观察者、数据科学从业者
- **它解决什么问题**：将分散在不同论文中的衰老时钟算法整合到统一接口，用 GPU 加速批量计算
- **试跑门槛**：中。需要 Python 环境、CUDA 支持的 GPU（或降级到 CPU 模式）、甲基化数据集；README 提供示例但数据获取需额外准备
- **许可证与数据**：MIT 许可证，代码可商用；示例数据来源待核查，真实甲基化数据需从公开数据库或合作实验室获取
- **维护成本**：中。依赖 PyTorch、CUDA 驱动、甲基化数据预处理；算法更新需跟踪原始论文
- **可做成什么**：算法拆解文章、衰老时钟对比表、数据清洗教程、Jupyter Notebook 演示、研究方法科普
- **可交付物**：README 试跑笔记、不同时钟模型对比表、数据预处理脚本、技术博客文章、小红书/公众号选题
- **最低成本验证**：今天只跑 README 示例，截图输出结果，整理 3 条要点：支持哪些时钟、输入数据格式、计算速度对比
- **成功指标**：能成功加载示例数据并输出至少一种时钟的计算结果，或清楚说明数据获取障碍
- **停止条件**：无法获取测试用甲基化数据、GPU 环境配置成本超 4 小时、依赖版本冲突无法解决
- **二次开发路径**：做成衰老时钟算法科普系列（每种时钟的论文背景、适用场景、局限）；整理公开甲基化数据集清单；开发简化版数据预处理工具
- **售后或合规风险**：高
- **合规边界**：只能写"算法复现""研究工具试跑""数据科学教程"，严禁包装成"测你的生理年龄""健康评分""抗衰效果验证"等面向个人的健康判断工具
- **今天最小动作**：克隆仓库，安装依赖，跑通 README 第一个示例或记录卡住的步骤，写 3 条试跑要点
