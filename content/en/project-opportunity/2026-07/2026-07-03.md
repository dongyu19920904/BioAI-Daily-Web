## 今日优先项目

### 1. 血压与脑年龄关联分析项目（Yuangang-Pan/Association-of-blood-pressure-with-brain-ages）

血压是最容易在可穿戴设备上持续追踪的生命体征之一，而脑年龄（brain age）是当前 longevity 领域最受关注的生物标志物之一。这个 Python 项目把两者连接起来，且代码开源可试跑，适合做成科普内容或工具导航条目。

- **证据来源：** [GitHub - Yuangang-Pan/Association-of-blood-pressure-with-brain-ages](https://github.com/Yuangang-Pan/Association-of-blood-pressure-with-brain-ages)（Stars: 2，2026-06-17）
- **可信度：** 中（学术研究项目，代码公开，但尚无同行评审论文链接，需自行验证方法）
- **目标鱼塘：** 长寿内容读者、关注高血压与认知健康的中年用户、健康管理从业者、可穿戴设备用户
- **它解决什么问题：** 用 DWI（弥散加权成像）和 T1 MRI 数据估算脑年龄，分析血压变化与脑年龄加速老化的关联，为"量化大脑老化"提供可复现的方法参考
- **试跑门槛：** 中。主要门槛是 MRI 数据集（需要开放数据集如 UK Biobank 替代数据），Python 环境依赖（FSL/FreeSurfer 等神经影像工具链）
- **可做成什么：** 内容拆解 / 试跑教程 / 工具导航条目 / 资料库条目
- **可交付物：** README 试跑笔记、"血压→脑年龄"研究地图对比表、脑年龄时钟工具导航卡
- **最低成本验证：** 今天只读 README，整理依赖清单，写"脑年龄是什么、怎么测、有哪些开放工具"3 条要点
- **二次开发路径：** 后续可做"脑年龄估算工具横向对比表"（含 BrainAge、ENIGMA、本项目），沉淀成资料库条目或小红书系列
- **售后或合规风险：** 中
- **合规边界：** 只写"研究显示血压可能与脑年龄加速老化相关"，不写"高血压导致脑老化"或诊断建议。所有内容定位为信息整理和研究观察，明确注明非医疗建议
- **今天最小动作：** 打开 README，截图依赖结构，写一条小红书选题："你的血压，在悄悄加速大脑老化？——脑年龄研究怎么看"

### 3. Affinage：基因组尺度基因功能注释 LLM 流水线

这是一个用 LLM 批量整理基因功能文献的工具，对 longevity 领域意义在于：长寿相关基因（FOXO3、SIRT1、APOE 等）的功能注释长期散落在数千篇论文中，Affinage 提供了一条可复用的信息汇聚路径，适合做成"长寿基因资料库"的数据清洗脚本参考。

- **证据来源：** [Papers.cool - Affinage arxiv:2607.02217](https://papers.cool/arxiv/2607.02217)（2026-07-02）
- **可信度：** 中（预印本，尚未同行评审，但技术路径清晰）
- **目标鱼塘：** 科研学习者、独立开发者、长寿内容创作者（需要可靠基因功能资料来源）、健康管理从业者
- **它解决什么问题：** 把 LLM 变成批量基因功能文献综述工具，解决"一个基因要读几十篇论文"的效率问题，输出可复用的结构化注释
- **试跑门槛：** 中。需要 Python + LLM API key（OpenAI/Claude），基因列表可以自选（用 longevity 相关基因子集）
- **可做成什么：** 试跑教程 / 数据集整理 / 长寿基因资料库条目
- **可交付物：** 用 Affinage 跑 5-10 个长寿相关基因的输出结果截图 + 笔记，做成"AI 怎么帮我整理长寿基因知识库"教程草稿
- **最低成本验证：** 今天只读论文摘要 + 看 GitHub repo（如有）的 README，整理"它能输出什么格式、需要什么输入"3 条要点
- **二次开发路径：** 用 Affinage 批量生成 FOXO3、SIRT1、APOE、TERT、KLOTHO 等基因的功能注释，沉淀成"长寿基因知识库"，后续可做导航页或 AI 问答小工具
- **售后或合规风险：** 低（信息整理工具，无医疗宣称）
- **合规边界：** 输出定位为"基因功能文献整理"，不做诊断或干预建议
- **今天最小动作：** 找 Affinage 论文的 GitHub 链接（论文中通常有），读 README，列出"运行它需要准备什么"清单

## 值得观察

**1. aDNA 古代 DNA 年龄时钟（Malaevleo/aDNA_aging_clocks）**
- 用古代 DNA 预测死亡年龄，属于 epigenetic clock 的前沿变体。目前仅 1 star，数据获取门槛高（古代 DNA BED 文件非公开），试跑难度大，目标鱼塘不清晰（不适合普通长寿内容读者）。
- **暂时不动原因：** 数据不可得，试跑重，目标鱼塘窄（仅适合古基因组学研究者），短期内难以做成可交付内容。
- **跟踪信号：** 如果作者后续发布开放数据集或教程，可以做成"表观遗传时钟进化史"内容线索。

**2. 印度城市儿童双重营养不良研究**
- 与 longevity 的关联是"早期营养状态影响长期衰老轨迹"，但目标鱼塘（印度低收入儿童健康）与当前读者群不匹配。
- **暂时不动原因：** 地域针对性强，鱼塘偏差大，短期内难以转化为本地内容或工具。
- **跟踪信号：** 如果后续出现中国城市儿童类似研究，可做"营养与长期衰老"内容连接。

**3. Neuron-Aware Data Selection（LLM 自蒸馏论文）**
- 技术上涉及专业领域 LLM 的数据选择优化，理论上可用于构建 longevity 专业领域小模型。
- **暂时不动原因：** 实现门槛极高，需要模型训练资源，短期内无法做成可交付内容，维护成本过高。
- **跟踪信号：** 如果有人用该方法训练出 longevity 领域微调模型并开源，值得立刻跟进。
