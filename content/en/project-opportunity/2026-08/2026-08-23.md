## 先看结论（可引用项目判断）

1. **epiage-skill 是目前最易本地试跑的表观遗传时钟集合工具之一。**
   Canonical repo：[github.com/gangchen/epiage-skill](https://github.com/gangchen/epiage-skill)（2026-08-09 发布，Stars: 2）。依赖仅 pandas + numpy，无需联网，今天可以在有 Python 环境的机器上直接 pip 安装试跑。适合独立开发者、健康内容创作者和生物信息学习者做工具导航和试跑教程。**不能做什么**：README 自述不等于临床验证，24 种时钟的输出是研究性估算值，不能用于个人诊断、临床决策或抗衰效果宣称。

2. **维生素 D 与轻度认知障碍的关联研究提供了一条有节制价值的内容线索。**
   来源：ScienceDaily 引用的初步研究（2026-08-22），[原文链接](https://www.sciencedaily.com/releases/2026/08/260822015138.htm)。该研究为观察性初步发现，样本量和设计细节未公开，结论是"值得进一步研究"，不是因果证明。今天适合做"研究解读 + 合规风险提示"类内容，**不能写成"补 D 能防痴呆"**。

3. **格陵兰鲨鱼眼睛抗衰机制是 longevity 科普的优质素材，但距离应用极远。**
   来源：ScienceDaily（2026-08-21），[原文链接](https://www.sciencedaily.com/releases/2026/08/260821012232.htm)。研究对象是野生动物，发现 DNA 修复机制与视网膜长寿有关。今天适合做"生物长寿机制科普"类选题，**不能推论为人类视力干预方案**。

## 今日优先项目

### 1. epiage-skill — 24 种表观遗传时钟本地 Agent 工具

这是目前极少数把多种主流表观遗传时钟（GrimAge、Horvath、PhenoAge、DunedinPoAm 等）打包成可离线运行 Agent Skill 的开源项目。依赖极轻（pandas + numpy），对独立开发者友好，今天就能试跑。

- **证据来源：** [github.com/gangchen/epiage-skill](https://github.com/gangchen/epiage-skill)，GitHub Trending，发布于 2026-08-09
- **可信度：** 中（Stars 仅 2，项目刚发布，功能真实性需本地验证）
- **目标鱼塘：** 独立开发者、生物信息学习者、longevity 内容创作者、健康管理从业者想了解表观遗传时钟原理的读者
- **它解决什么问题：** 把散落在各论文中的多种老化时钟算法集成为一个可本地调用的工具，省去从头复现的成本
- **试跑门槛：** 低——有 Python 环境即可，无 GPU 需求，无需联网
- **可做成什么：** 试跑教程 / 工具导航条目 / 对比表（各时钟输入要求 vs 输出含义）/ 资料库条目
- **可交付物：** README 试跑笔记、24 种时钟对比表（名称 / 发表年 / 输入数据类型 / 主要应用场景）、小红书/公众号选题草稿
- **最低成本验证：** 今天只需克隆仓库、读完 README、记录安装步骤是否顺畅、截图，整理成 3 条要点
- **二次开发路径：** 做成"表观遗传时钟导航页"（每种时钟一条卡片：输入要求 / 适用人群 / 局限）；后续可衍生为付费数据清洗模板或课程模块
- **售后或合规风险：** 中
- **合规边界：** 所有输出结果只写"研究性估算"，明确说明不能替代临床检测，不宣称能预测个体寿命或用于诊断
- **今天最小动作：** `git clone`，读 README，记录依赖安装过程，截图，写 3 条要点（是什么 / 能跑什么 / 不能做什么）

## 值得观察

1. **epiage-skill 后续版本和社区反馈**
   Stars 目前仅 2，项目功能声称覆盖 24 种时钟，但尚无外部复现报告。暂不大力推广，等待 2-3 周看是否有用户反馈或 issue 验证功能完整性。原因：项目太新，可靠性未经社区验证。

2. **Greenland Shark 眼睛 DNA 修复机制的后续论文**
   当前来源是科普报道，原始论文和研究设计细节未见。DNA 修复 → 人类视力保护的转化路径极长，目前只适合作为科普素材，不适合做产品或服务方向。原因：基础研究阶段，应用距离极远。

3. **维生素 D 认知改善研究的完整论文**
   ScienceDaily 摘要未给出论文 DOI，样本量和研究设计不明。适合持续追踪，等原始论文发表后再做深度拆解。原因：初步发现，缺乏原始论文细节，过早引用有误导风险。

4. **Fight Aging! 周报中提到的具体创业/投资动态**
   本次素材中 Fight Aging! 内文未展开，但该来源历史上会提及早期 longevity 初创和资金动向。值得每周定期浏览，但今天暂无具体线索可操作。原因：当前素材内容不完整，需要打开全文才能判断。

## 今天别碰

1. **任何声称"补充维生素 D 可治疗或预防认知障碍"的内容方向**
   当前证据是初步观察性研究，研究对象为特定亚组（轻度认知障碍 + 睡眠问题），因果关系未建立。制作该类内容若夸大结论，面临医疗信息合规风险，且一旦后续研究不能复现，内容公信力受损。

2. **基于 epiage-skill 输出结果做"个人生物年龄评估服务"**
   该工具输入需要 DNA 甲基化数据（普通用户无法自行获取），输出是研究性估算，项目刚发布未经广泛验证。包装成个人服务涉及医疗数据处理合规问题，维护成本高，今天不具备条件。

3. **格陵兰鲨鱼研究 → 人类抗衰产品选题**
   此类"动物研究 → 人类应用"的强关联叙事在 longevity 领域是最常见的误导模式之一。动物研究不能直接推论人类应用效果，做成产品导向内容会损害内容可信度。
