## 今日优先项目

### IBAR-ROGEN/Aging — 甲基化衰老时钟 + 长寿变异注释工具集

这是一个活跃于2026年7月底的生物信息学项目，覆盖甲基化衰老时钟、长寿相关变异注释和等位基因频率比较三个模块，全部基于 Jupyter Notebook，适合拆解成教程或资料库条目。它服务的方向（aging clock、基因组长寿研究）和本项目方向高度重合，且 notebook 格式降低了试跑门槛。

- **证据来源：** [IBAR-ROGEN/Aging](https://github.com/IBAR-ROGEN/Aging)，GitHub Trending，2026-07-31
- **可信度：** 中（项目来自研究机构账号，功能描述清晰，但 stars 极低，需核实 notebook 是否可运行）
- **目标鱼塘：** 长寿内容读者、科研学习者、健康管理从业者、独立开发者
- **它解决什么问题：** 提供可复现的甲基化衰老时钟计算流程和长寿基因变异注释，让非专业用户也能跑通衰老生物标志物分析的基本流程
- **试跑门槛：** 中（需要 Python/Jupyter 环境，可能需要示例数据；甲基化数据来源需另行确认）
- **可做成什么：** 试跑教程、资料库条目、工具导航、内容拆解（「衰老时钟到底怎么算？」）
- **可交付物：** README 试跑笔记、3条要点总结、工具对比表（该项目 vs 其他衰老时钟工具）、资料库条目
- **最低成本验证：** 今天只需：克隆仓库 → 读 README → 看 notebook 结构 → 整理"它能算什么/不能算什么/需要什么数据"3 条要点
- **二次开发路径：** 整理成「衰老时钟工具导航」栏目 → 后续可加入 Horvath Clock、GrimAge 等对比 → 形成长期可更新的资料库页
- **售后或合规风险：** 低（纯研究工具，不涉及个人诊断）
- **合规边界：** 表达为"研究用衰老标志物分析工具"，不写"测出你的真实年龄"或任何临床诊断暗示
- **今天最小动作：** 打开 README，整理 3 条要点，截一张 notebook 目录结构图，写一条小红书选题「用代码算出生物年龄？这个开源项目拆解」

### DaisyCuttie/scMLEAge — 单细胞衰老时钟（scRNA-seq 方向）

单细胞层面的衰老时钟是当前 aging 研究前沿之一，这个项目打标签清晰（single-cell、aging-clock、scanpy），基于 scanpy 生态，notebook 格式。对懂 Python 的内容创作者或开发者来说，可以拆解成「单细胞衰老时钟原理」科普或与 bulk RNA 衰老时钟的对比内容。

- **证据来源：** [DaisyCuttie/scMLEAge](https://github.com/DaisyCuttie/scMLEAge)，GitHub Trending，2026-07-29
- **可信度：** 中（标签精准，使用 scanpy 等主流工具，但 stars 低，项目成熟度待验证）
- **目标鱼塘：** 科研学习者、长寿内容读者（进阶向）、独立开发者
- **它解决什么问题：** 在单细胞分辨率下估算细胞衰老程度，比 bulk 衰老时钟更细粒度
- **试跑门槛：** 中（需要 scanpy 环境，单细胞数据较大，但 notebook 格式可以只读流程不跑数据）
- **可做成什么：** 内容拆解、资料库条目、与 IBAR-ROGEN/Aging 的对比表
- **可交付物：** 「bulk vs 单细胞衰老时钟」对比表、README 试跑笔记、资料库条目
- **最低成本验证：** 今天只读 notebook 流程，不跑数据，整理"它的输入/输出/适用场景"一张表
- **二次开发路径：** 与 IBAR-ROGEN/Aging 合并成「衰老时钟方法论地图」，后续可扩展成教程系列
- **售后或合规风险：** 低
- **合规边界：** 定位为研究工具介绍，不涉及个人检测或诊断
- **今天最小动作：** 读 README，和 IBAR-ROGEN/Aging 放在同一张对比表里（方法 / 数据输入 / 适用场景 / 门槛）

## 值得观察

**1. xvviix/chrona-bio — 临床团队生物年龄智能**
- 描述为"面向临床团队的生物年龄智能"，但 stars=1，HTML 项目，功能和数据来源完全不透明
- 暂不动原因：功能不可验证，临床宣称重，不清楚是否有实质内容还是仅为 landing page
- 跟踪方向：一周后再看，若有 README 或 demo 可试跑再评估

**2. 超声神经调控框架论文（arxiv 2608.06321）**
- 开源计算框架，将超声场映射到神经激活图，非侵入式神经调控方向
- 暂不动原因：技术门槛极高（物理/神经科学交叉），目标鱼塘不在当前核心人群，短期内难以做成内容或工具
- 跟踪方向：若后续出现面向消费级 TUS 设备的应用，可重新评估

**3. 小型认知行为基础模型论文（arxiv 2608.05224）**
- 用行为数据训练认知代理模型，Psych-101 数据集覆盖 160 个实验
- 暂不动原因：与 aging/longevity 核心方向关联较弱，更偏认知科学基础研究，短期内难以做成面向本项目鱼塘的内容
- 跟踪方向：若有衰老认知变化或痴呆相关应用出现，可重新纳入

**4. 藻类食品 Gates 基金资助项目**
- Gates Foundation 资助藻类可持续食品研究，与长寿/营养/健康存在潜在关联
- 暂不动原因：当前描述停留在食品科技和粮食安全方向，longevity 关联需要更多证据
- 跟踪方向：若后续有"藻类与衰老干预"的具体研究结论再纳入
