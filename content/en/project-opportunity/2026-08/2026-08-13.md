## 今日优先项目

### 1. NeuroBloom — 纵向认知监测与康复平台

这是今天素材里完成度最高、最容易试跑的项目。35项认知任务、6个域、双语支持、含数字生物标志物提取，方向精准对齐认知老化和神经系统疾病。即便 stars 只有1，功能描述清晰、技术栈现代，值得今天就跑 README。

- **证据来源：** https://github.com/Adit-Mugdha-das/NeuroBloom
- **可信度：** 中（学生/小团队项目，功能描述详尽但未经独立验证）
- **目标鱼塘：** 认知衰退内容读者、照护者、神经科普自媒体、健康管理从业者
- **它解决什么问题：** 提供免费的、可追踪的认知功能纵向监测工具，填补非临床环境下认知变化追踪的空白
- **试跑门槛：** 中（Svelte 前端，需 Node 环境；本地部署约 20-30 分钟）
- **可做成什么：** 试跑教程 / 内容拆解 / 工具导航条目 / 对比表（与 BrainHQ、Cambridge Brain Sciences 等商业工具对比）
- **可交付物：** README 试跑笔记 + 截图 + "免费认知测试工具对比表"资料库条目
- **最低成本验证：** 今天只读 README，记录：能跑哪些测试、依赖安装是否顺利、界面截图3张
- **二次开发路径：** ① 做"免费认知自测工具导航"小页面；② 整理成照护者资源包；③ 写"什么是数字认知生物标志物"科普文
- **售后或合规风险：** 中
- **合规边界：** 只介绍工具功能和测试设计，不声称能诊断疾病、预测痴呆风险或替代临床评估。表述为"研究性工具"和"个人参考"
- **今天最小动作：** clone 仓库 → 跑 `npm install` → 截图3张 → 写3条要点笔记备用

### 2. 社交生活与生物年龄加速：GrimAge2 研究线索

1309人、15年纵向队列，童年逆境与正向社交经历对 GrimAge2（表观遗传时钟）的影响。这是目前主流长寿媒体讨论最少、但对普通人最有触动感的"生活方式→衰老速率"证据链之一。选题价值高，写法可以非常接地气。

- **证据来源：** https://www.news-medical.net/news/20260812/Your-social-life-may-leave-a-mark-on-how-fast-you-age.aspx
- **可信度：** 中高（同行评审纵向队列研究，媒体报道，原始论文需另查核）
- **目标鱼塘：** 长寿内容读者、关注心理健康与抗衰的中年用户、健康科普自媒体
- **它解决什么问题：** 将"社交体验"和"表观遗传衰老速率"连接起来，给普通读者提供可感知的衰老干预视角
- **试跑门槛：** 低（只需读原文、整理关键数据点）
- **可做成什么：** 内容拆解 / 小红书/公众号选题 / 数据点资料库条目
- **可交付物：** 3条要点 + 1张"影响生物年龄的社会因素"简表 + 1条朋友圈/小红书选题草稿
- **最低成本验证：** 今天读完这篇新闻，记录：样本量、随访年限、GrimAge2 关键结论、1个可用数据点
- **二次开发路径：** ① 积累成"表观遗传时钟"内容专题；② 与其他生活方式干预文献并排做"影响生物年龄的因素地图"；③ 延伸做 GrimAge2 工具导航（现有检测服务资料包）
- **售后或合规风险：** 低
- **合规边界：** 只陈述研究观察，不推荐具体干预，不暗示"多社交就能延寿"，加注"相关性研究，不构成医学建议"
- **今天最小动作：** 整理3条关键数据点 → 写1条小红书选题："你的社交圈正在影响你的衰老速度——表观遗传学怎么说"

## 值得观察

**1. visionbyangelic/Brain-Aging**
Stars 3，Jupyter Notebook，方向对，但描述为空。暂时不动原因：不知道数据集、方法和可运行性，需等作者补充 README 或查看 notebook 内容。下周再看。

**2. laabidi-ahmed-ai/brain-age-mri-prediction**
用 OASIS 数据集 + EfficientNet-B0 做脑年龄预测，是教学项目。方向好，但 OASIS 数据集申请有门槛，试跑需要有 MRI 数据访问权限。暂时不动原因：试跑门槛中高，今天没有优先级更高的理由先跑它。适合下周作为"AI脑年龄预测入门教程"素材。

**3. ScreenShot 组合用药筛选基础模型**
覆盖3700种药物+6000个生物样本，技术含量高。方向与长寿/老龄化有间接关联（抗癌组合用药），但目标鱼塘不够直接，试跑门槛高，且论文刚发布未经充分验证。值得加入资料库标记，3个月后看引用情况。

**4. M-Net 医学影像分割**
纯方法论文，与老龄化关联弱。若后续有脑MRI分割的应用场景可回来参考，目前不在优先列表。
