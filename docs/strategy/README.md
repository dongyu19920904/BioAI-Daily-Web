## 使用方式

以后 Codex/CowAgent 在做 AI 延续学相关项目时，优先参考：

```text
1. 用户是否有真实痛点
2. 用户是否能输入自己的数据
3. 结果是否适合分享
4. 是否能接入 19.9 元 AI 报告
5. 是否能进入 AI 延续学 100 万人实验
```
