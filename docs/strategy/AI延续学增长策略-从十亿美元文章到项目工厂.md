# AI 延续学增长策略：从《How to Earn a Billion Dollars》到项目工厂

日期：2026-06-27

原始资料归档：

`docs/strategy/original/2026-06-how-to-earn-a-billion-dollars-paul-graham.txt`

## 一句话结论

AI 延续学要达成“今年让 1 亿人知道，100 万人参与”，不能只做日报，也不能只做一堆小工具。它必须变成一个能持续产生指数传播的项目工厂：

```text
AI 延续学日报 -> 每日商机雷达
每日项目 -> 用户可参与的实验
项目主页 -> 信任资产和入口
分享结果 -> 自传播
AI 报告/社群/课程 -> 变现
```

## 这篇资料给我们的核心启发

Paul Graham 文章里最重要的不是“如何赚 10 亿美元”，而是两个变量：

```text
最终规模 = 当前规模 * 增长率 * 持续时间
```

对 AI 延续学来说，对应关系是：

```text
1 亿人知道 = 传播规模
100 万人参与 = 参与规模
收入 = 参与人数 * 付费转化率 * 客单价
```

所以问题不是“再做一个什么项目”，而是：

```text
每天做什么，能让用户愿意告诉朋友？
每周做什么，能让增长持续？
每月做什么，能进入更大的市场？
```

## 目标倒推

从 2026-06-27 到 2026-12-31，大约 27 周。

如果目标是 100 万参与者，所需增长率非常高：

```text
从 100 人开始：每周约 40% 增长
从 1,000 人开始：每周约 29% 增长
从 10,000 人开始：每周约 19% 增长
从 50,000 人开始：每周约 12% 增长
```

因此，前两个月最重要的不是赚钱，而是找到一个能自然传播的“滩头市场”。

## AI 延续学的滩头市场

不要一开始就讲“生命延续”“抗衰”“长寿医学”，这些概念太大，也容易让普通人觉得虚。

更好的滩头市场是：

```text
我和我爸妈的体检报告看不懂
```

原因：

- 每年大量人都有体检报告。
- 用户已经有真实数据。
- 用户天然焦虑但不知道怎么行动。
- 适合生成可分享的个人结果。
- 适合 19.9 元 AI 详细解读。
- 能自然扩展到睡眠、血糖、炎症、运动、父母健康、年度复盘。

当前已经做出来的 `bioage.aivora.cn` 就应该变成第一个核心滩头项目。

## 正确的产品叙事

不建议主打：

```text
AI 帮你抗衰
AI 帮你延寿
AI 算你的真实生物年龄
```

建议主打：

```text
AI 延续学 100 万人实验
用 AI 看懂体检、睡眠和生活数据
找到你的延续力短板
每周做一个低风险改善实验
```

核心口号：

```text
不是追求长生不老，而是让每个人更早看懂自己的健康信号。
```

## 每日项目工厂机制

每天从 AI 延续学日报的商机里筛选一个项目，但筛选标准必须改。

过去容易犯的错：

```text
看到一个新论文、新工具、新 GitHub repo，就改成网页。
```

正确标准：

```text
这个项目能不能让一个普通人输入自己的数据？
结果能不能一句话讲明白？
结果能不能生成分享图？
是否能引导 19.9 元 AI 报告？
是否能引导进 100 万人实验？
```

## 每日项目评分表

每个候选项目按 100 分打分：

```text
真实痛点：20 分
用户能输入自己的数据：15 分
结果适合分享：15 分
一天内能做出 MVP：15 分
原项目许可证清晰：10 分
能接 19.9 AI 报告：10 分
能进入 AI 延续学主线：10 分
医疗/法律风险可控：5 分
```

执行规则：

```text
低于 70 分：不做
70-85 分：做轻量 MVP
85 分以上：做重点项目，考虑独立子域名和内容投放
```

## 项目形态模板

每个新项目必须有同一套结构：

```text
1. 用户输入
2. 即时结果
3. 模块解释
4. 分享卡片
5. 原 GitHub 项目来源
6. 非医疗声明
7. 加入 AI 延续学 100 万人实验
8. 19.9 元 AI 详细报告
9. 返回个人主页项目库
```

项目不是孤岛，而是同一场运动的一个实验编号。

例子：

```text
实验 001：体检年龄差
实验 002：睡眠恢复年龄
实验 003：炎症风险观察
实验 004：父母体检单 AI 解读
实验 005：血糖波动复盘
```

## 传播机制

PG 文章里的关键判断是：增长率来自用户喜欢到会告诉朋友。

AI 延续学的“告诉朋友”不能靠说教，必须靠结果卡片。

每个项目都要生成类似：

```text
我的体检年龄差：-7.2 岁
我的延续力短板：糖代谢
我正在参加 AI 延续学 100 万人实验
```

传播渠道：

```text
朋友圈
微信群
小红书
B站/抖音短视频
公众号
GitHub
AI 工具导航站
```

内容形式：

```text
1 分钟看懂一个体检指标
我用 AI 改造了一个国外开源长寿项目
帮爸妈看体检报告前，先看这 9 个指标
为什么同龄人的体检年龄差会不一样
```

## 变现设计

不要一开始卖很重的产品。先卖低价、即时、强相关的东西。

推荐阶梯：

```text
0 元：免费工具和简版结果
19.9 元：AI 详细解读报告
49 元：父母体检报告解读
199 元：年度延续力档案
399-999 元：社群陪跑/课程/AI 工具包
```

当前最应该优先做：

```text
19.9 元 AI 详细解读报告
```

原因：

- 和工具结果强关联。
- 用户决策成本低。
- 交付可以自动化。
- 可以验证真实付费意愿。
- 可以给 Aivora 店铺导流。

## Codex/CowAgent 每天应该做什么

每天固定执行：

```text
1. 读取线上 AI 延续学日报
2. 提取商机项目
3. 用评分表打分
4. 搜索对应 GitHub 原项目
5. 检查许可证
6. 生成项目 brief
7. 复制项目模板
8. 做成中文网页工具
9. 部署 GitHub Pages
10. 写入个人主页项目库
11. 生成小红书/公众号/短视频内容包
12. 记录访问、参与、付费数据
```

每天产物：

```text
一个可访问网页
一个 GitHub 仓库
一条个人主页项目记录
一套内容发布素材
一条复盘记录
```

## 最重要的判断标准

以后每个项目都问这三个问题：

```text
1. 用户会不会觉得“这是我的问题”？
2. 用户会不会把结果发给朋友？
3. 用户会不会愿意花 19.9 元看更详细的解释？
```

如果三个问题都是否定，就算它很前沿，也不应该做。
