# 日报通俗化修正（2026-10-17）

## 问题与做法

栏目和视觉已基本符合要求，本次只解决内容像论文摘要的问题，不重新设计页面。原稿一条药物新闻包含多组炎症指标、试验编号和药物代号；骨骼新闻连续解释多条分子链路；三句摘要又重复术语。这些细节并非普通读者判断进展和研究阶段所必需。

今天的正文采用普通 AI 日报的短资讯写法：先说明发生了什么，再交代用途或意义，最后用一句白话说明限制。删去次要指标和方法链，不靠机械截断，不新增未经支持的医疗结论。来源链接仍融入正文，没有恢复独立粗体导语或证据标签。
