## 编辑标准

- 一条先讲实际事件，再结合事实解释一至三个必要概念；数量不设配额，不为科普硬塞术语。
- 保留一项值得知道的结果、方法或比较设计。需要时同时保留样本量、时长和主要结果，不以数字少作为质量指标。
- TOP 参考 150-230 字，可按证据内容调整；不是扩充套话或把论文方法整段搬进来。
- 概念就近解释，不加关键词表、教学卡或独立导语。样式、字体、颜色与栏目顺序不变。
- 来源继续融入正文，锚文本说明能继续了解什么。不编论文、教程或搜索链接，不重复固定的“点击了解更多”。
- 小鼠、细胞、人体、公司自述、预印本和临床结果分别表达；安全边界融入一两句，不用一串标签压过内容。
